# 造景组合试放

Windows 双击 `open-review.cmd`。macOS 在 Finder 中双击 `open-review.command`，或在终端运行 `./open-review.command`。macOS 会按主屏可用区域居中，在后台打开窗体。点击「潮汐馆 · 缸体定制原型 · 造景组合试放」窗口，再用以下按键查看。

| 按键 | 操作 |
|---|---|
| `1` / `←` | 加勒比风格暖礁 |
| `2` / `→` | 淡水沉木与水草 |
| `A` / `D` | 绕缸转向 |
| `V` | 切换斜视和顶视 |
| `B` | 对比同缸空底与已摆放布局 |
| `Esc` | 关闭试放 |

两组都使用 15 × 8 × 5.1 米占地与高度，调用游戏的 `ShellContentsView` 实例化正式目录中的资产。海水把珊瑚、海绵落在真实礁面上，保留裂谷入口、礁拱口和前 1.24 米开放水道。淡水展示竖根盘、横伸伏木、沉木隧道、低展根网，以及后侧高水草与前侧低丛，保留前 1.22 米开放水道。附着物的高度取对应岩石或沉木的实际网格。窗口使用独立照明，并为审查采用开放观察面。游戏存档无读写。

`./open-review.command --check` 在原生 Godot 以无头模式重新校验尺寸、是否在缸内、所用目录项与水道范围。`./open-review.command --capture` 重拍两张代表图和当次 `placement.json`。如果首选植物未部署，窗口会从同一游戏目录选已部署的同类备用项，实用 ID 和备用数量写入报告。

- [加勒比风格暖礁](caribbean-reef.webp)
- [淡水沉木与水草](freshwater-root-bank.webp)
- [试放验证报告](placement.json)

入口依赖当前本地游戏工程、Foundry Godot Mono 及 macOS Xcode 命令行工具（由入口从仓库内源文件编译窗口辅助）。窗口放到普通窗口底层，启动后可能需要从 Dock 点开。

代表图来自正式 100 项目录。暖礁 19 件、淡水 25 件全部在缸内，淡水前景含两丛细发草甸。交付后清理旧入口、重复报告及重复截图共 526,859 字节。
