# D 批海岸生态造景

本批交付八个完整摆件。每件保留六面 Foundry 原画、封闭薄壳或实体、带内嵌贴图的可编辑 Blender 源、GLB、Godot 六向及双斜向灰模和贴图图证。原画 / 灰模 / 材质系代理画面审核，用户验收待定。

| 对象 | 主要结构与摆放 | 三角面 |
|---|---|---:|
| 巨藻林丛 | 温带冷水硬底，大型立景。共用固着器、分开的柔软长茎、叶基气囊和稀疏冠层 | 984 / 1000 |
| 鳗草疏草床 | 温带砂泥底，狭带叶和五个横走根茎上的疏草丛 | 592 / 600 |
| 单叶糖海带 | 温带硬底，中低前景。舌形阔带与短柄，原画附带的小石脚与藻体为一件 | 540 / 600 |
| 石莼褶片丛 | 温带浅水岩面，宽褶薄片从小盘固着器生长 | 588 / 1000 |
| 龟草矮草床 | 加勒比暖水沙地，低拱宽带草坪 | 596 / 600 |
| 仙掌藻节片丛 | 暖水浅礁和砂地，带真实厚度的肾形节片链，微小水流 | 940 / 1000 |
| 角叉菜叉枝丛 | 温带北大西洋岩岸低前景，扁平二叉藻体与小盘固着器 | 648 / 1000 |
| 黑红树笋根泥岸 | 河口潮间带，低泥床及 30 处直立笋根；长期浸没的暖水展缸没有这一栖地 | 1188 / 1200 |

物种来源、尺寸与生态分组写在 [subjects.json](subjects.json)。鳗草、龟草是真正的海洋开花植物，其余海草状对象参考不同海藻类群。角叉菜依据资料放温带组。现有红树支根木为高架拱根，本件对应黑红树从泥面向上透气的笋根。游戏里各条目的尺寸作造景用，鳗草与龟草叶宽稍作夸张以便读出像素轮廓。

六向板用于逐件解释形体和选取色源，交叉重叠与未见的内部位置由本种布局作艺术解释。每件布局单独落在 [layouts.py](layouts.py)，闭壳与石木的完整三角数记入 [预算门](budget.validation.json)。模型使用单网格、单表面、单张 256×256 不透明近邻色图，两面的 UV 各有色源。实机细看可见部分柔叶尖的低面折角。全部八件在空白 Blender 进程打开 packed 源、导回并规范化，当前 GLB 逐字节重现。

七件柔性海草/海藻按现有 PlantSway 编码 UV2 相位与根至尖权重，COLOR 编码实际局部支点；黑红树采用静态。每个活动物件在实际 Godot Compatibility 的三实例、三相位有独立摆动，同一相位逐像素相同，循环端最多有少量栅格边缘差；CPU 追踪固定根点位移为零，真实网格根端复核在游戏材料验证中。黑红树 30 处根端均进入本件实际泥面，构建有相交射线采样。活动模型备选 StandardMaterial3D 接入时应关闭 vertex_color_use_as_albedo，以免把支点颜色当上色。
