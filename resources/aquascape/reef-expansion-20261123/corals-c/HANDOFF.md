# 暖水礁附着物 C 批

[候选目录](candidate-catalog.json)含 14 件独立造型，394–974 三角。每件可编辑 Blender、GLB、六面原画、逐件验证报告及原生灰模与贴图实拍图都在相应目录。用户原画与最终接受均待审。

## 来源与制作

[参数和来源](profile.json)记录造型用途、海区、水层、附着方式和预算。鹿角珊瑚与麋角珊瑚使用有资料支持的物种形态。其余按命名的生长型与用途提供，暖水造景的海区标记可供主题展缸组合。形态核对参考 NOAA Fisheries、Smithsonian、澳大利亚海洋科学研究所和对应生态来源。

先以 Foundry 生成同一物件材质意向的正右背左俯仰六视，先看六面中结构、取色和相机的适用范围，再重建灰模。摆放实例采用干涉体分支、厚壳和实体切空的差集以形成真实连接及杯口。模型可测尺寸为游戏表现用。源图是生成意向，几处侧面存在轻度俯角，轮廓用途和不足逐件登记。

取色共用六面中最适面源的近邻规则，使用 1536 像素单图集、单网格和单不透明材质。海绵压低生成原画中大尺度暗影，实际暗腔由真实几何和局部调色共同表现。硬珊瑚下部固定，细密珊瑚杯、壳面珊瑚虫和部分脑纹保留像素表现。海扇将细密网保留为较大网孔，其他软体也以静止姿态接入素材库。柔性组织与真实摆动另验。

## 验证与收尾

实际 Blender 冷读与 GLB 的位置、UV 和内嵌贴图逐件互证，保留密封、连通性、基面及所用几何分布。全部采用普通石或阔叶代理档位，整件不超过 600 或 1000 三角硬上限。候选目录标准预算门 14/14 通过。Godot 4.7.1 使用 Compatibility 后端从冷 GLB 读出每件一网格、最近邻材质，实看正右背左俯仰及斜视，同光灰/色逐件同图保留。单件技术、图面取舍和色面限制记入各自 validation，不将原生画面等同用户验收。

Build 与证据入口为同目录脚本，GPU 冷读入口在 work 的 corals-c/native_review.sh。只清理精简拼图已覆盖的可再生抓帧与替换掉的同名 Blender 自动备份。原始图、现在的源/成品和必要证据保留，精确字节见 work 的 retention.json。
