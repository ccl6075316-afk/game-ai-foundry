# 资料库双视对齐、头嘴补皮与有限鳍根：2026-11-06旗鱼返修

本条是实际制作方法记录，不代表旗鱼或其他鱼已获用户接受。物种参数入口为 `resources/volume-fish/atlantic-sailfish-library-aligned-20261106.json`，本轮证据在游戏 `plans/reviews/sailfish-whale-shape-20261105/sailfish/HANDOFF.md`。普通Sailfish艺术模型的精确身份、年龄和实测尺度未知。

先冻结同口径端点和统一比例，直接截取资料库实际三角面，分别核对身体侧高、横宽、开口后界、下颌端及吻尖；鳍混入的截面不能当颅部。用户明确要求尽量匹配库双视后，退掉此前“保留圆吻”的人为豁免。稀疏头笼应有独立上下颌体积和真实口内壁，不能靠整头缩放、竖端面或额外尖突代替。旧父版本曾在头笼之外的头肩过渡变形，故“新头笼仅从X=.224开始”不等于帆鳍前根所依赖的身体未受影响。

侧图绕到额顶/下巴会拉丝，并可能复制眼鳃。缺失皮肤可按源表面修复卡走实际Foundry辅助生图；完整提示、作业、实际尺寸和唯一原图保留。生成无特征二维皮肤与原后段、原眼、面部色标、完整原生唇域分别管理，明确合成范围，不能宣称全头保留原像素。二维纵横均须变化，不把横向坐标夹成一行。新Blender材质先清空节点再建一个明确输出；默认active输出残留会导致GLB没有baseColorTexture，即使编辑器存在贴图节点。

全鳍完整根域来自原实际根点、边与有限根面，以及新拓扑完整解剖基边界。投到源参数面时只恢复正确的身体交点分支，不用任意最近点把不同源点挤成同一位置。两层采用相同归一化前四骨权重，根支持取实际身体有限三角形重心权重。先拟合原有支撑顶点，再细分实际失败的边/面；只采三角重心会漏掉边四分点和60/20/20内点。朝一个未修顶点无限细分只会堆面，必须同时包含顶点自身。

原源域在新拓扑上新增的支持点仍须纳入真正根域，不能因作者临时自由面标签漏算；重新核对完整旧域与新基边界后，实际根点和有限面接触均受原界限约束。自由面离开根部后建立有限间隙，不以扩大根区、根缝、穿透容差或降低动作幅度放行。极窄基区的新中面支持可能折叠而使双面实际射线缺失；修局部单元几何或以平滑小偏移替代折叠支持，不扩大射线排除区。

完整根面采样为标准导出器的显式可选项，默认历史行为不变；`local`仅诊断，不能冒充177/490覆盖。整鳍碰撞根缝距离应同时使用真实根面和真实根边连续线段，稀疏点列不能代表长边；仍同时限制距离和嵌入深度，不将长边两端之间的任意区域纳入根域。本次连续边修正未消除右胸鳍负例，实际通过来自之后的模型修正。

静止/四动作四分之一周期通过仍可能漏切换。本轮完整490抓到第二背鳍根约.512mm、右胸鳍过渡约.050mm的穿入；按实际失败面局部小偏移与身体蒙皮修正，再冻结集中复验，原3936历史490没有重跑或移植。本鱼最终3968面，240cm上限4000，未达到3500优选；其他鱼不继承数值。

尾柄接头在身体和尾鳍精确同一平面比较完整截面，插入深度也不得超过原根缝。三角—平面交点必须逐三角配对，再求截面；把所有边交点全局reshape会错连不同面，制造假误差。回归包含两片相距很远、输入顺序打乱的三角形。旧错误检查器报告明确退休，不能作为几何负例。尾根厚度需从该身体截面平滑退到自由鳍薄缘，不把一个点接住当完整接头。

最终新进程只读blend导出，再逐字节比较完整GLB；相同则同时覆盖几何、UV/法线、蒙皮、材质图像、骨架与clip。GPU冷读也只读GLB，不运行旧静态工厂或兼容性未知的旧LOD钩子。报告通过与用户外观接受、正式入口安装、完整SOP完成分开记录。清理保留唯一输入、当前源/成品、完整数值及少数代表姿态，退休密集采样和重复导出，不把已退休缓存说成直接可复核。
