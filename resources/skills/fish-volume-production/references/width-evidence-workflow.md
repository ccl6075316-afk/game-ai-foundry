## 一、怎样找宽度资料

1. 先确定学名、野生型/品系、展示全长和年龄/性别；未知就保留未知。本批鲫鱼是野生型Carassius auratus，不混用C.carassius、银鲫或观赏金鱼。
2. 先查本地库和已有同种来源中的实际资料/测量。缺口再按“学名 + morphometrics / body width / body thickness / head width / cross section / 3D scan / CT / museum specimen”搜索；中文用“学名或物种 + 体宽/体厚/头宽/形态测量/横截面”。优先同种原始论文表、博物馆实测数据与原始扫描；机构物种卡用于定性，商业/生成模型只作辅助。
3. 阅读方法和表头，记录原单位、样本n、全长TL/标准长SL/叉长FL、具体测位、保存/活体状态、群体与性别。保存原始值，不把不同组的最大值拼成一尾鱼。
4. 分别找唇缘、眼前颅部、眼平面、眼后头宽、面颊/鳃盖、肩部、躯干和尾柄。最大鱼宽可能在头部；眼间宽不等于含眼球的头宽；FishShapes Mouth_width是两侧颌关节间距，不是唇缘/口裂宽。
5. 等比例换算单独标公式与条件。例如罗非鱼AA10组37.5cm全长/5.1cm眼后头宽，换到40cm为5.44cm；这是B级情景，不是40cm实鱼测量，也没有证明吻端每个截面的宽度。

## 二、证据与未知分别记账

- A：同种实测个体或论文报告均值，保留原始定义和条件。
- B：明确条件的换算，或测法/表格有局限的调查值。
- C：机构资料的定性形态约束。
- D：工程造型提案。即使受A/B约束，也不升级成实测。

**当前头型约束（2026-11-01要求与11-02补充合并）：D标签不是凭空设头型的许可。** 头部参数须有可核对的来源与部位对应；同种横宽不足时，允许体型接近的同属/同科资料或已审模型作近缘厚度参考，用户指定样板优先。每个吻端/眼前/眼位/鳃盖/肩部控制点记录参考物种、文件与SHA、量测位置、原值或像素/模型比例、长度归一化和限制；近缘模型不冒充同种实测，接受不转移。只有最大体宽、定性“圆头”或无对应部位的其他鱼曲线仍不能放行；插值只连接有依据的测位，未覆盖部位保留未知。无可用同种/近缘参考时可按任务需要生成俯视辅助并实际审核、量图，明确非生物实测，不再机械要求“缺同种必须生图”。

**同日用户进一步纠正**：公开在线3D展示、商业及免费模型的预览图同样要查、实际看和比较，不能因为模型文件下不来就判定没有参考。优先多角度的正、俯、侧斜及灰模预览，记录原链接/作者/物种身份/图片哈希，核对相机与口开度，提取可辨部位的比例；作者建模与真实扫描分别注明，不把商业标题或“写实”当作生物准确性保证。不能从带透视的预览直接读出精确厘米。没有正俯视时允许用真实侧斜照片与清楚的模型侧斜预览共同核对，不强行生成正交图。2026-11-01本批红皇帝鱼两张、虹鳟一张生成参考已被用户拒绝，几何/材质均不得采用；原图和失败记录在游戏 `experiments/five-fish-head-evidence-20261101/generated-reference-rejection.validation.json`。

小样本观察范围不是种群上下限；人为±10%或±15%试探带不是置信区间。数据自相矛盾、错鱼种、未定义测位等问题写入拒绝/限制清单，不默默修正或用模型自身参数循环证明。

## 三、先量现有模型，再定每鱼包络

读取用户实际看到的GLB、当前源blend与查看器比例并冻结SHA。glTF X为长度、Y为高度、Z为左右；全宽W不含鱼鳍。用实际三角面与X平面相交量截面，排除鱼鳍，只取明确身体/口内所有权。记录工程坐标s=从最前点后退/整鱼可见纵向跨度；s不是SL，也不会自动变成眼位或鳃盖测位。

在原画配准唇缘、眼前、眼位、鳃盖后、肩部、背/臀鳍起点和尾鳍基；粗定位标误差。头部和躯干分别设宽度站，避免沿一条通用纺锤曲线削成针尖。“独立控制颅部、鳃盖”指不同位置的参数，不要求拆分模型。

先保存整版候选数据：每站位置、现有W/H、拟试W/H、依据等级、来源和未知值；再展示HTML蓝/橙宽度曲线、真实切片与拟试轮廓、原画和多视图。缺资料的口裂宽、骨性眼间宽继续为null。

## 四、生成图只提出形体假设

**2026-11-01生成参考顺序（11-02近缘补充优先）**：头宽先查同种实测和测位定义；缺尺寸资料时继续找真实背视、俯视或斜视照片，实际打开原图核对。若真实背视不足，先核验当前允许的近缘资料/指定样板；确实仍无适用来源，再按任务需要把生成背视图作为造型探索，未覆盖部位仍记未知。搜索结果里有图、读到图注或取得网页元数据，都不能记成“已看过实拍”。403、下载失败和未取得的图继续记为未取得，不用生成图提前填补。

头部证据须独立于最大体宽。HW最大头宽、IOW骨性眼间宽、含眼头宽、侧面头高和口裂宽分别记录；不能用身体W/H、旧profile approved、90%窄头负例或侧影不变证明真实头型。实际量源画眼位、鳃盖与吻端的截面，并记配准误差。相近尺寸换算仍是有条件情景，不能变成物种硬界限。

真实风格/灰模/像素图均可用于讨论正/俯/斜视体积，但不从生成像素计算“实鱼尺寸”。保留提示词、模型、参考图SHA、实际审阅与缺陷。本批四张Nano Banana2头部图有厚唇、鼓眼、裁切、三视不同形及比例不一致，未作为尺寸真值或直接建模目标。

## 六、实际审阅与后续验证
