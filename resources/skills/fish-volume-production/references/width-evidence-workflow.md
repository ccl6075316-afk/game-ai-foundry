# 鱼类横向形体：查证、参数、HTML审阅与模型试验

2026-10-31，用户已认可罗非鱼、蓝鳃太阳鱼、鲫鱼和草鱼的宽度外观，并要求完整保留此法供后续物种复用。认可绑定实际模型SHA，见 `resources/volume-fish/width-reference-20261031/archive.validation.json`；不是完整鳍/身体/动作专项通过，也不把本批尺寸当成下一鱼默认值。

## 一、怎样找宽度资料

1. 先确定学名、野生型/品系、展示全长和年龄/性别；未知就保留未知。本批鲫鱼是野生型Carassius auratus，不混用C.carassius、银鲫或观赏金鱼。
2. 按“学名 + morphometrics / body width / body thickness / head width / cross section / 3D scan / CT / museum specimen”搜索；中文用“学名或物种 + 体宽/体厚/头宽/形态测量/横截面”。优先同种原始论文表、博物馆实测数据与原始扫描；机构物种卡用于定性，商业/生成模型只作辅助。
3. 阅读方法和表头，记录原单位、样本n、全长TL/标准长SL/叉长FL、具体测位、保存/活体状态、群体与性别。保存原始值，不把不同组的最大值拼成一尾鱼。
4. 分别找唇缘、眼前颅部、眼平面、眼后头宽、面颊/鳃盖、肩部、躯干和尾柄。最大鱼宽可能在头部；眼间宽不等于含眼球的头宽；FishShapes Mouth_width是两侧颌关节间距，不是唇缘/口裂宽。
5. 等比例换算单独标公式与条件。例如罗非鱼AA10组37.5cm全长/5.1cm眼后头宽，换到40cm为5.44cm；这是B级情景，不是40cm实鱼测量，也没有证明吻端每个截面的宽度。

## 二、证据与未知分别记账

- A：同种实测个体或论文报告均值，保留原始定义和条件。
- B：明确条件的换算，或测法/表格有局限的调查值。
- C：机构资料的定性形态约束。
- D：工程造型提案。即使受A/B约束，也不升级成实测。

小样本观察范围不是种群上下限；人为±10%或±15%试探带不是置信区间。数据自相矛盾、错鱼种、未定义测位等问题写入拒绝/限制清单，不默默修正或用模型自身参数循环证明。

## 三、先量现有模型，再定每鱼包络

读取用户实际看到的GLB、当前源blend与查看器比例并冻结SHA。glTF X为长度、Y为高度、Z为左右；全宽W不含鱼鳍。用实际三角面与X平面相交量截面，排除鱼鳍，只取明确身体/口内所有权。记录工程坐标s=从最前点后退/整鱼可见纵向跨度；s不是SL，也不会自动变成眼位或鳃盖测位。

在原画配准唇缘、眼前、眼位、鳃盖后、肩部、背/臀鳍起点和尾鳍基；粗定位标误差。头部和躯干分别设宽度站，避免沿一条通用纺锤曲线削成针尖。“独立控制颅部、鳃盖”指不同位置的参数，不要求拆分模型。

先保存整版候选数据：每站位置、现有W/H、拟试W/H、依据等级、来源和未知值；再展示HTML蓝/橙宽度曲线、真实切片与拟试轮廓、原画和多视图。缺资料的口裂宽、骨性眼间宽继续为null。

## 四、生成图只提出形体假设

真实风格/灰模/像素图均可用于讨论正/俯/斜视体积，但不从生成像素计算“实鱼尺寸”。保留提示词、模型、参考图SHA、实际审阅与缺陷。本批四张Nano Banana2头部图有厚唇、鼓眼、裁切、三视不同形及比例不一致，未作为尺寸真值或直接建模目标。

## 五、用户认可的方法：在原结构上调左右宽度

`prepare_transverse_width_trial.py` 冻结每鱼正值PCHIP增益场，`author_transverse_width_trial.py` 写入全新可编辑源，`portable/export_source.py` 新进程冷导出，`validate_transverse_width_trial.py` 重新量实际有限截面并核对保留项，`capture_transverse_width_trial.gd` 拍摄同相位、同相机、同显示尺度的旧/新多视及动作代表帧。

只改Z及按雅可比逆转置更新法线，保留X/Y、拓扑、原尺寸UV/图像、部位归属、蒙皮、骨架、绑定和原生动画。有限三角面实际截面可略不同于连续场目标，必须记录导出后的真实数值。原宽度趋零的数学端点不直接做巨大比值；用近端有限站并限制光滑过渡。

本批宽度阶段的面数/骨骼：罗非1710/18，蓝鳃1494/18，鲫鱼1440/18，草鱼1682/18，全部修改前后不变。各自顶点数、54动画通道及实际数据也不变；不是要求所有未来鱼固定18骨或同一面数。

## 六、实际审阅与后续验证

先嘴：实际开口、上下颌、下唇、左右与跨唇像素；再看全部鳍和其余部位。灰模正/俯/斜视检查厚薄、平端和凹口；材质检查纹样拉伸、眼纹归属与已有缺陷。保留共同相机的侧影0像素差证明，但不拿它证明正面正确。

互动查看器要直接冷读保存GLB，提供同鱼原版/试验版切换、环绕、缩放、灰模与正常动作。相同物种切换保留镜头尺度；不同体长物种重新适配取景。每鱼实际看图；不能用上一鱼的外观接受代替下一鱼。

横向场覆盖鳍时，支持面与鳍顶点都已改变。旧177/490/077/动作报告失效；代表截图和原动画字节保留不能证明完整动态安全。先稳定形体，再集中执行完整鳍根/鳍面、身体/GPU、动作与导出冷读及sop-check。只有宽度外观认可时明确记录接受范围，正式入口保持原版。
