# 大西洋鲑：预算站位和原生像素覆盖

当前状态以游戏`experiments/atlantic-salmon-portable-trial-20261031/manifest.json`为准：R3操作者候选，1980三角、8鳍、19骨，未替换游戏正式资源、未取得用户整鱼接受。

1. **制作预算使用展示体长。** 用户于本鱼制作时更新了[四档预算](display-length-budget.md)：≤120cm为1500/2000，>120–300cm为3500/4000，>300–600cm为5500/6000，>600cm为7500/8000（优选/硬上限）。本鱼73.66cm仍是2000上限。`cli/fish_budget.py`集中检查，作者和最终门使用同一规则；最终门核对实际viewer长度，不能只填写更长物种最大值。边界、NaN、超限、错误viewer缩放均有负例。
2. **旧口裂采样不是永久轮廓控制点。** 2092三角首版被拒。本鱼删除的仅为旧slit_path新增的1700/1795和1790/1795两处插值站，已证明上下轮廓和半宽在邻站间精确共线，且不属于任何原始体形控制、骨骼权重分界或鳍基；保留新7口缘站。不能把这次结果推广成任意删身体支撑环。完整头型/身体/动态门已复验。
3. **源像素覆盖用原生产采样规则。** 精确共线点删掉后，把顶点先四舍五入再交给另一个多边形画笔，可能误报像素差异。本鱼按建造器的原尺寸像素中心射线规则核对，8个自由背鳍共线点删除前后覆盖相同。通用`compact_free_fin_contour.native_pixel_mask`保存该规则，并有“连续轮廓相同但第二栅格器不同”的负例及真实改形检出。相同覆盖仍不证明动态相同。
4. **整鳍面通过不等于鳍根通过。** R2的490膜面全通过，脂鳍完整根带仍在24姿态超出1mm根缝限制，最差1.12mm。R3仅把本鱼脂鳍inset从0.00004改为0.00030原生单位，完整根带、膜面容差、动作全部不变；当前490与072同时通过。不把该inset当其他鱼的配方。
5. **辅助图透明边界是输入错误。** 第一版正面投影落到透明供体，已拒绝；本鱼调整自己投影宽度到0.10m，不放松不透明断言。作者失败信息现在输出实际供体XY、source-u和surface角色，便于直接定位。正面图只取受限中央与灰紫口内颜色；原眼、原曲唇和头型继续来自本鱼源图。

源图原生粉色侧带继续作为游戏设计，不能假称海水阶段大西洋鲑准确体色；隐藏横宽、年龄/性别及不可见配色仍未知。近景正/腹面的侧图拉伸、口内低面平面有局限。完整冷读、实际嘴/鳍/源图/动作画面和SOP通过后，保留当前源/资产及唯一证据，清理重复采样和旧候选，两仓库提交推送后再开始海鲈。
