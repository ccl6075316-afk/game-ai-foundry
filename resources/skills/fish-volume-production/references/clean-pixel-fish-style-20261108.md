2026-11-08 用户认可本地罗非鱼 C 风格，并要求记录定型、先烘焙罗非鱼试用。随后用户明确“不错 这个罗非定下来吧”，接受实际 C 烘焙外观。该版本已写入罗非鱼正式 blend/GLB；随后用户接受旗鱼和鲸鲨静态成品，并明确授权剩余鱼采用此方向重烘焙；这项授权不等于其余鱼已通过新材质验收。几何、UV、法线、蒙皮和骨架继续冻结，先稳定材质，再单独调整动作。当前记录见 `resources/volume-fish/nile-tilapia-clean-pixel-20261108.json`，完整生产 SOP 清单与本轮范围检查的状态分别记录。

## 风格锚点

视觉样板为 `resources/volume-fish/styles/clean-pixel-20261108/nile-tilapia-C.png`，SHA256 `45fe646d48d2ae3e03bd1bdd644504e98d27c5bd963681089d84d3851c48905a`。B 眼睛样板同目录 `nile-tilapia-B-eye.png`。样板是基于本地模型渲染的 AI 材质意向图，不能冒充真实照片、精确几何或已经完成的纹理。

- 继承本地成品鱼的自然比例、像素纹理、鳞片/斑纹和鳍条组织。减轻脏硬线，而非把整鱼改成大色块、低饱和、模糊或卡通。
- 眼睛采用 B 的方式：虹膜保留纹理，眼圈不突兀发白，瞳孔与小高光清晰，眼部融入头部。不添加眼皮、眉毛、睫毛、微笑，不跨鱼照抄虹膜颜色或大小。
- 轮廓和内部线使用接近局部固有色的深色。减轻尾鳍、腹鳍、胸鳍、背鳍接合处近黑重边；保留真实结构分界、完整鳍条及物种天然深色斑纹。
- 保留身体大范围体积明暗，减轻过硬、过深的细线和接缝。不全局提亮、不抹平阴影、不抹掉鳞片，不用纯色填满部位。
- 颜色、亮度与反光依物种。鲸鲨的灰蓝或温润配色不是统一色板。强镜面反光应由实际光照/材质响应产生，不能靠自发光掩盖烘焙问题。

## 制作与比较

用户已选定 C 时直接使用 C 的颜色信息，不把 C 仅当风格参考重新生成整鱼。按[原 UV 烘焙卡](whale-shark-multiview-color.md)划分眼、嘴、口内、身体及每片鳍，排除遮挡和背景。本轮 C 是有光照的截图编辑，需记录光照分离或色彩变化转移方法，不能将摄影阴影再次叠入底色后称为忠实烘焙。

以正式现有源和 GLB 为基线，保持几何、UV、法线、蒙皮、骨架、动作和透明覆盖。两侧、俯、腹、斜、嘴/眼近景与代表动作统一机位光照比较。图面外观接受、映射质量、正式资产验收分别记录。

本轮原提示与方法记录保留于游戏 `plans/reviews/static-fish-release-20261108/nile_tilapia/`，罗非鱼正式源和 GLB 是后续维护基础。旧 work 试验、候选和媒体按用户要求退休，不能再把这些历史路径作为可用重放入口。长期样板在 resources 中保留。
