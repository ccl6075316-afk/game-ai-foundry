# 原结构横宽试验：参数分区不等于拆分网格

适用：用户只要求在既有鱼上调整俯视各测位的宽度。头颅、眼平面、面颊/鳃盖、肩部只是宽度场的独立控制位置，不要求新增或拆分部件。不要把制作说明写成论文的建模要求。

使用正值连续增益场 `Z'=g(s)Z`，保留纵向X、垂直Y。先冻结输入源、每鱼参数和基线；PCHIP或其他插值仅是工程方法，不能赋予参数生物实测身份。源有真实口裂时，嘴/口内共同跟随同一场并核对有限三角的真实开口。法线按形变雅可比逆转置变换，不能只移动顶点保留旧光照。

若使用打包单网格源，保持拓扑、精确UV、部位归属、蒙皮、绑定、原图和动画。`author_transverse_width_trial.py` 将冻结的逐点场写入全新可编辑源；源所有权签名只在明确作者阶段重算，再用未放宽的守卫独立冷导出，并比较实际属性和原生动作数据。不能将改变的源签名改写成旧模型通过。

横宽场覆盖鱼鳍时，其真实几何和身体支持面都改变。静止连续变形、原生动作数据保留、少量代表截图均不能代替新的完整鳍根/整鳍面、身体GPU和动作门。实验不直接替换正式入口；先局部看形，修稳冻结后集中完整验收。

当前例：`resources/volume-fish/nile-width-trial-20261031.json` 为罗非鱼独立推断参数，`projects/fishing-2d/experiments/nile-width-trial-20261031/manifest.json` 为当前试验状态。没有新增部件，仍1710面。嘴部多视、截面重测、侧影0像素差和代表动作证据分别记录，不宣称整鱼或其他鱼通过。
