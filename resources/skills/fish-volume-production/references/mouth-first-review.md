# 嘴第一、鳍第二：实际证据与整鱼约束同时成立

2026-10-31用户在实际列表中否决蓝鳃、鲫鱼、草鱼嘴部：横线式口裂、下唇线和开口没有落实、左右补色/接续丢失、前端大块平色。原SOP已有这些要求；本卡明确执行停点，不把重复文字当问题已解决。

## 顺序

基础来源/文件/导入检查后，第一优先嘴，第二优先全部适用鳍，其余再查。嘴部局部未完成，就留在返修；不启动最终整套验证、不推进下一鱼、不写整鱼或嘴部通过。已有合法源/未受影响部件保留，依赖变化时标失效并复验。

## 嘴部必须指出实际东西在哪里

| 项 | 必须拿出的同鱼证据 | 不可放行的替代 |
|---|---|---|
| 下唇线/上下口缘/口角 | 未清洗原图上的独立标注和模型对应曲线；区分上下唇，保持源画布 | 参数里写了slit_path；借别鱼坐标 |
| 真实开口 | 正侧斜/腹视灰模、口腔内壁/剖视；按本鱼口缘和开度形成有限负空间 | 一条恒宽切缝、仅黑线或小倒角 |
| 上下颌与下巴/脸颊 | 整头上下文和近景，实体体积及连续过渡成立 | 插一片下巴、加独立唇管、削尖颅部 |
| 左右与跨口缘颜色 | 左正右/斜/腹材质近景，外皮、唇缘、口内分区及实际原尺寸供体XY/UV | 额头/下巴小矩形淡入整个前吻；抹掉真正唇线或块纹 |
| 原画像素接续 | 同姿态原图/成品对照、完整像素簇/灰阶/唇色/描边的归属和衔接 | “黑斑消失”“RGB相同”“图集不透明” |

已接受罗非鱼R11作为完整制作方法与质量对照，不能移植其嘴型、唇坐标、颜色或生物比例。查各鱼资料和本鱼原图，模糊项保留未知。不得再把“静态嘴/低面近似”作为省略上述项的授权。

## 同时约束整鱼预算及其余质量

整鱼按[展示体长四档预算](display-length-budget.md)执行：≤120cm为1500/2000，>120–300cm为3500/4000，>300–600cm为5500/6000，>600cm为7500/8000（优选/硬上限），统计实际最终装配的身体、口腔、上下颌、全部鳍双侧/封边及附层。每个局部候选报修改前/后总数、部位数与当前剩余预算。蓝鳃1980面的旧候选没有新增高密嘴的空间，须替换/重布低效局部拓扑，必要调整也必须保住既有形态和完整鳍，不缩小鳍根选区、不丢内壁、不以少计部件过预算。

修嘴保留画风、头吻包络、眼、身体/尾柄、鳍形/厚度/完整根带、蒙皮/正常动作、原图和真实材质；任何代价都写入影响清单。局部成功后仍需同一最终源/冷读/身体/鳍/动作及SOP完整门。

## 审核记录不能替结果找理由

记录逐项填写“源标注、实际模型部位、对应图/剖视、检查结论和缺项”。看到了问题就判失败；机械报告只承担其声明的范围。用户否决绑定的模型哈希不得再由原自动finalize脚本写成通过。修订候选须新哈希、新证据；操作审核仍不得冒充用户接受。
