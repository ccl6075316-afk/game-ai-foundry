# 褐鳟：源端点、预算和实际失败姿态

逐鱼状态只读游戏 `experiments/brown-trout-portable-trial-20261031/manifest.json`。当前为R6静态资产搭配R9动作配置；操作者检查通过，未替换正式资源、未取得用户整鱼接受。1998三角、8鳍、19骨。

1. **不对称吻端不能用邻列中位数直接包络。** 本鱼最后一列只剩下颌，邻列上吻污染中位数，使中心UV落进透明区。保留失败，核对本列原始alpha跨度283..308px后仅改这一端点；不降低不透明检查。隐藏横宽继续独立标为制作推断。
2. **预算要数最后导出的全部三角。** 初版2070被挡住。`compact_free_fin_contour.compact`只删除精确共线、方向一致、远离完整鳍根及权重过渡的自由边点，保留本鱼原始像素多边形覆盖；本鱼背鳍删8点，另独立配置内网格。面积/栅格相同不代表三角化或动态相同，必须重新看鳍及测完整490。不得删身体动态支撑环或抬高2000上限。
3. **四姿态预检不能预测所有动态失败。** R4预检通过，完整490仍发现胸腹鳍穿体。`run_local_diagnostic --extra-poses <JSON>`可加入本鱼失败报告中的精确action/seconds，默认四姿态保留，所有声明姿态必须真的导出，不能只检查静态。当前本鱼增加4个历史最差姿态；仍不是完整490或连续时间证明。
4. **加密不等于修复。** R7把少量面从鳍内改到腹鳍基，仍1998三角，反而出现更深的动态内嵌，拒绝推广。R9采用R6静态结构：本鱼配对鳍较薄、自由膜离体余量增加，完整鳍基保留；原生循环、四动作弯曲和最大2.5控制范围保留，另加身体波动由0.20调整到0.10弧度。R8的0.14仍失败。该动作调整是本鱼制作调校，不是生物实测、通用配方或取消正常动作的许可；实际动作画面及当前完整490/072都复验通过，旧报告不转移。
5. **长嘴补色起点属于本鱼。** `lip_source_transport.surface_start_u` / `surface_start_fade_u`允许明确配置。旧默认值对本鱼后口角开始太晚，当前从源图1413/1597开始。真正唇缘仍沿本鱼原图运输，口内使用独立二维ROI；可选反转口深方向只影响口内颜色，不改变几何。
6. **补皮羽化只在本鱼允许的足迹内。** `register_body_donor`可选`completion_feather_px`，默认0保持旧行为。此鱼仅在明确未保护域内向内6像素过渡；保护区RGBA精确保持，生成体外透明处不混回已去掉的鳍。测试同时覆盖保护域、边界过渡及透明鳍鬼影；不能拿羽化掩盖错误轮廓。
7. **固定整画布对照可硬编码，外观判断不能。** `compose_source_comparison.py`按实际相机宽度与模型比例投影整张原图，不各自裁剪拟合轮廓；同时自动列出本鱼全部真实鳍与原尺寸裁图/冷读材质/灰模。单鳍缩略图独立取景，不能据此证明面积相等。
8. **只改动作时保留已固化静态资产。** R9单独冻结新动作配置、spec、鳍计划及新进程最终门，沿用已保存且完全相同的R6源和GLB，不为新时间戳复制导出。交付清单同时绑定模型与动作哈希。
