| 阶段 | 联动目标 | 必须看见的结果 |
|---|---|---|
| 接近 | 游动与猎物位置协调，在咬取前开始开口 | 不提前长时间僵硬张嘴，时序按实际参考调整 |
| 扩张张口 | 头部抬起、下颌下降、口底随之展开 | 上下口沿分离，入口后有可读的口腔深度，口角自然展开 |
| 压缩咬合 | 上颌向前下方伸出参与咬合，下颌抬起 | 上颌参与而非鼻尖单独掀盖；猎物通过入口，不穿唇或下巴 |
| 大食物处理（条件分支） | 先夹持，再水平左右甩头，身体继续游动 | 食物随实际夹持点运动；小食物不强制甩头，不能用道具消失冒充撕裂或吞咽 |
| 回收 | 颌部回到静息位置，头部与游动接续 | 闭合与回收衔接自然，不突然跳回、不反复拉出皮膜 |

阶段可重叠，表格不是每一步严格串行；最大张口不等于最大上颌前伸。统一的是控制含义和阶段关系，逐鱼调整颌支点、头部俯仰、上下颌运动范围、口角/口底形变及阶段时长。角度、位移与时间须标参考量或制作近似；不复制被拒绝版本的27°、位移和3.4秒为默认值。具体骨骼父子关系也须按效果验证，不能把“下颌挂上颌”规定为解剖事实。鲸鲨另用滤食分支，保持可开合口腔，不能套咬取小鱼的同一动作。

### 证据与适用范围

- [Wilga等2001，Fig.2及正文](https://doi.org/10.1093/icb/41.6.1248)：提供扩张、压缩、回收的比较机制；窄头双髻鲨与柠檬鲨示例支持共用框架，不提供项目全部鲨鱼的统一幅度。可读[论文PDF](https://faculty.weber.edu/rmeyers/CVA/shark%20jaw%20protrusion.pdf)。
- [Motta等1997，柠檬鲨](https://pubmed.ncbi.nlm.nih.gov/9326502/)：高速摄影和肌电研究支持真鲨科上颌参与摄食；摄入、食物操纵、口内运输有区别，不能每次都播放同一大幅咬击。
- [Porcher2023，同种黑鳍礁鲨](https://doi.org/10.1163/1568539X-bja10213)及[补充视频](https://doi.org/10.6084/m9.figshare.22268605)：已看首分钟概览及29–42秒片段，用于行为核对，局部颌细节不足以定量。近缘[Gardiner等2014 Movie S1](https://doi.org/10.1371/journal.pone.0093036.s004)为C. limbatus，已看咬取序列；250fps拍摄、30fps回放，不能拿慢放秒数当真实时长。不是C. melanopterus。
- [Motta等2010，鲸鲨](https://pubmed.ncbi.nlm.nih.gov/20817493/)支持滤食分支；本轮补查文献记录，没有新下载模型或制作贴图。

### R2前伸机制复核：有前伸不等于做对了前伸

用户先指出“撅嘴”感，随后自行查证鲨鱼可前伸，要求核对真实运动是否与项目一致。本轮没有取消前伸或修改模型。重新查Motta等1997全文pp2771及Wilga等2001 pp1251–1252：研究真鲨科示例的上颌前伸参与闭口，上颌后段前移与前段向腹侧的运动受颅部连接约束；不能将整块嘴同向平移当完整机制。柠檬鲨多数摄入咬合在开始闭口后出现前伸，峰值常在闭口末段；这是近缘参考，不冒充黑鳍礁鲨同种标定。

只读反事实脚本 `feeding/r2/audit_protrusion.py` 固定下颌角与头抬量，仅切换前伸0/1。实际口沿上下点位移差小于7.5e-9原生单位，口距变化小于7.2e-9；鼻端无此次前伸位移。这证明当前控制是上下颌共同平移，缺少上颌对闭口的独立贡献，并不是鼻子本身被前推。当前最大张口已达60%前伸、前伸峰值仍有85%张口控制量，未按上述参考落实咬合时序。整鱼travel逐段smoothstep导致每个关键点速度为0，也会放大嘴先动/鱼停顿的观感。

后续应重做上颌前后段与下颌闭合的关系、将主要前伸放入压缩咬合阶段，身体前进使用连续速度；不能简单把前伸全部清零，也不能凭当前资料断言本鱼的精确幅度/角度。R2状态改为运动学待修，原局部碰撞/冷导报告仍只证明其技术范围。复核仅保留小型脚本与JSON、来源与结论，没有新模型/帧或待清理缓存。

## 1. 先分清哪些可以复用

| 可复用的制作方法 | 下一种仍须独立确定 |
|---|---|
| 同种实拍/标本/公开3D预览查证，源图与实际有限网格对照 | 学名、展示体长、年龄/姿态、长度口径、头吻和躯干测位 |
| 有体积的连续鳍面、完整曲面鳍基、根到自由缘渐薄 | 鳍库存、前后缘弧度、跨度、倾角、厚度参数与根区 |
| 尾柄完整截面接续尾鳍，异尾作为连续实体处理 | 上下叶比例、后缘缺口、尾轴、尾柄宽高和过渡长度 |
| 下位口裂与鼻端分开处理，真实开口/上下颌和原生唇域 | 口位、弧度、宽度、齿/口内、是否需要开合动作；鲸鲨等不能套下位口 |
| 背腹皮肤连续过渡，鳍上下层按拓扑归属 | 真实斑点、黑尖、白带、腹色、眼和鳃裂，不套统一去黑 |
| 冷源导出、实际导入/缓存与正常动作检查 | 骨骼数量、原生轨道、控制范围、接触余量和最终面预算 |

真鲨/双髻鲨常见两背鳍、成对胸/腹鳍、臀鳍和一片尾鳍，共8片解剖鳍；尾鳍上下叶可含不同骨骼，不能因此记成两片鳍。部分鲨类无臀鳍或有鳍棘，库存须逐种查，不能把8写成“全部鲨鱼固定8”。胸鳍和腹鳍须分别标名，避免把前方大胸鳍误叫腹鳍后修错位置。

## 2. 俯视形体与来源合同

按最新[宽度依据流程](width-evidence-workflow.md)：先明确TL/SL/吻至尾鳍基的对应和画布配准，冻结同一参考的最大身体横宽/长度及峰位；鳍不计入躯干宽。头吻各段写为同一来源的W(t)/Wmax，并记录吻端、眼前、眼位、头后/鳃裂、胸鳍基和尾柄的解剖映射。双髻鲨另记头翼总宽、中央颅部/颈部宽和躯干宽，不能让锤头或胸鳍跨度冒充“最大躯干宽”。来源未支持的测位保持待查，不能填上一鱼的流线曲线。

顺序为同种实测/数据库 → 同种侧/背/腹/斜实拍及同标本多视 → 公开3D/扫描或商业模型实际多视预览。实际取得并查看后才记录证据；作者模型、扫描和照片投影分别注明。同种横宽不足时，按2026-11-02补充可采用体型接近的同属/同科或指定已审样板作近缘厚度参考，逐部位记录实际SHA、长度归一化与未知，不继承接受。仍无适用参考时再按任务需要生图并审核、量取生成参考，明确非生物实测。原始图片、测位标记、SHA和完整来源包保存；`volume source-replan`检查已接受原画复用，不能把网页链接或旧profile approved当成当前来源门。

连续轮廓与站间凹陷必须看，不能只报几个站点误差。模型最终宽度直接交实际有限三角面测量，不用生成函数的目标值冒充成品值。俯视头形正确也不能替代腹面口弧或侧面上下颌体积。

## 3. 鳍的连续体积与尾柄

从已独立分离的本种完整原画轮廓建连续展向/弦向中面，再建同源两层与自由缘/根面封口。大轮廓可以近似三角，有限鳍面不应出现一块块三角山包。边界/峰脊应是明确约束链，不由不规则三角化独立产生局部厚度峰；尾鳍凹口处分开处理连通弦区间，不能跨透明缺口求全局宽度。

完整根面贴实际身体曲面，两层不能各自钳到同一面造成塌陷。身体和鳍的蒙皮在完整有限根面上对应，单个点接触或最近顶点权重不够；长弦须在实际身体截站/铰接处支持。尾柄完整末端截面保持，与尾鳍厚根连续接续，不突然缩成纸片；端截面若本身与原图不符，先修来源对应，不能将错身体当绝对真值。

第一例旧3950面候选虽通过厚度/490，端视仍有9个鼓峰，被用户拒绝。拉普拉斯平滑曾塌根或残留楔形，不作推荐。最终连续脊线+单调鳍叶包络使实际端视只有1个连续峰，尾柄全宽误差约0.000104显示mm（冻结门0.5mm未改）。这些数值仅归本例。见[鳍型执行卡](fin-types-thickness-tail.md)和本鱼`continuous-tail-plan.json`。
