## 1. 先分清哪些可以复用

| 可复用的制作方法 | 下一种仍须独立确定 |
|---|---|
| 同种实拍/标本/公开3D预览查证，源图与实际有限网格对照 | 学名、展示体长、年龄/姿态、长度口径、头吻和躯干测位 |
| 有体积的连续鳍面、完整曲面鳍基、根到自由缘渐薄 | 鳍库存、前后缘弧度、跨度、倾角、厚度参数与根区 |
| 尾柄完整截面接续尾鳍，异尾作为连续实体处理 | 上下叶比例、后缘缺口、尾轴、尾柄宽高和过渡长度 |
| 下位口裂与鼻端分开处理，真实开口/上下颌和原生唇域 | 口位、弧度、宽度、齿/口内、是否需要开合动作；鲸鲨等不能套下位口 |
| 背腹皮肤连续过渡，鳍上下层按拓扑归属 | 真实斑点、黑尖、白带、腹色、眼和鳃裂，不套统一去黑 |
| 冷源导出、实际导入/缓存与正常动作检查 | 骨骼数量、原生轨道、控制范围、接触余量和最终面预算 |

真鲨/双髻鲨常见两背鳍、成对胸/腹鳍、臀鳍和一片尾鳍，共8片解剖鳍；尾鳍上下叶可含不同骨骼，不能因此记成两片鳍。部分鲨类无臀鳍或有鳍棘，库存须逐种查，不能把8写成“全部鲨鱼固定8”。胸鳍和腹鳍须分别标名，避免把前方大胸鳍误叫腹鳍后修错位置。

## 2. 俯视形体与来源合同

按最新[宽度依据流程](width-evidence-workflow.md)：先明确TL/SL/吻至尾鳍基的对应和画布配准，冻结同一参考的最大身体横宽/长度及峰位；鳍不计入躯干宽。头吻各段写为同一来源的W(t)/Wmax，并记录吻端、眼前、眼位、头后/鳃裂、胸鳍基和尾柄的解剖映射。双髻鲨另记头翼总宽、中央颅部/颈部宽和躯干宽，不能让锤头或胸鳍跨度冒充“最大躯干宽”。来源未支持的测位保持待查，不能填上一鱼的流线曲线。

顺序为同种实测/数据库 → 同种侧/背/腹/斜实拍及同标本多视 → 公开3D/扫描或商业模型实际多视预览。实际取得并查看后才记录证据；作者模型、扫描和照片投影分别注明。同种横宽不足时，按2026-11-02补充可采用体型接近的同属/同科或指定已审样板作近缘厚度参考，逐部位记录实际SHA、长度归一化与未知，不继承接受。仍无适用参考时再按任务需要生图并审核、量取生成参考，明确非生物实测。原始图片、测位标记、SHA和完整来源包保存；`volume source-replan`检查已接受原画复用，不能把网页链接或旧profile approved当成当前来源门。

连续轮廓与站间凹陷必须看，不能只报几个站点误差。模型最终宽度直接交实际有限三角面测量，不用生成函数的目标值冒充成品值。俯视头形正确也不能替代腹面口弧或侧面上下颌体积。

### 需要生成辅助俯视图时的描述骨架

下列是输入描述合同，不是保证图正确的咒语；先填本种已查证的形态差异，再实际审核。

> 同一条【学名/物种】、同一体态和同一原画画风的严格背侧正交俯视；头尾完整、身体中轴伸直，相机垂直鱼背，无透视缩短和翻滚。保留本种吻型、眼位、头颈过渡、鳃裂与身体宽度分布。左右胸鳍、腹鳍成对且自然展开，按原画/资料保留各自前后位置与轮廓。正中背鳍和垂直尾鳍从上方表现为有厚度的侧刃投影；尾鳍保持垂直异尾，不能横摊成鲸尾或复制成两片横向大叶。不要在吻端、身体中线或鳍后凭空增加鳍。背视只表现该视角实际可见的口部，不把腹面完整U口线印到鼻端。中性均匀照明、少遮挡、与已审核侧图相同体色与纹样、充足画布留白。

双髻鲨追加本种头翼前缘的中央/两侧凹口、圆凸/平直程度和眼所在外端；鲸鲨另查宽扁头、端位口、斑点和尾型。正/腹图另做并明确机位，不能把背、腹、正面混称“俯视”。正面鳍的投影宽包含倾角，不能直接当法向组织厚度。

## 3. 鳍的连续体积与尾柄

从已独立分离的本种完整原画轮廓建连续展向/弦向中面，再建同源两层与自由缘/根面封口。大轮廓可以近似三角，有限鳍面不应出现一块块三角山包。边界/峰脊应是明确约束链，不由不规则三角化独立产生局部厚度峰；尾鳍凹口处分开处理连通弦区间，不能跨透明缺口求全局宽度。

完整根面贴实际身体曲面，两层不能各自钳到同一面造成塌陷。身体和鳍的蒙皮在完整有限根面上对应，单个点接触或最近顶点权重不够；长弦须在实际身体截站/铰接处支持。尾柄完整末端截面保持，与尾鳍厚根连续接续，不突然缩成纸片；端截面若本身与原图不符，先修来源对应，不能将错身体当绝对真值。

第一例旧3950面候选虽通过厚度/490，端视仍有9个鼓峰，被用户拒绝。拉普拉斯平滑曾塌根或残留楔形，不作推荐。最终连续脊线+单调鳍叶包络使实际端视只有1个连续峰，尾柄全宽误差约0.000104显示mm（冻结门0.5mm未改）。这些数值仅归本例。见[鳍型执行卡](fin-types-thickness-tail.md)和本鱼`continuous-tail-plan.json`。

逐鳍检查整鱼与隔离鳍的正反端视、侧/俯/腹、两面斜灰模及贴图。完整内埋根面会在隔离时暴露，应结合整鱼判可见自由面，但不能借“内埋”掩盖体外折痕。一次收齐全部鳍的问题，不能让用户依次点名背、胸、腹、尾才检查。

## 4. 嘴、材质与预览的常见误判

下位口中央尖折和鼻端尖是两个问题。第一例先改鼻子，口弧V角仍在，是实际执行错误。随后在真实口腔/外皮公共边同时圆顺X和Z，保留口角、横宽、开口和上下颌；原生唇域重映射。实际腹/腹斜旧新对照与九条口腔深度射线分别验证。不能抹圆黑线或追加鼻尖代替几何修复。

鳍上下层依同源参数/拓扑运输到曲根，不能用逐面法线阈值硬切色；身体使用连续角向供体，避免三角拼块、整行拖色和正面嘴线重复。黑尖白带属于本种纹样，不能用辐鳍鱼去黑经验全删。派生去光照颜色与逐字原像素保持的声明要分开，侧眼、鳃裂和已确认唇域保护。

闪烁先分几何重叠、导入LOD、贴图透明和相机深度精度。浏览器near/far按实际取景更新；静态与游动、拖动/缩放均实际看。Godot导入可能重排数组/骨名表示和简化动画，比较有向三角角点、UV、骨名权重、RGBA、实际LOD与动作姿态；有实证需要时保存原生引擎clip，不假设GLB动画通道相同就动作相同。

### 可以复用的新判断

- 头翼与前躯干采用同一侧/腹投影包络的共享曲面控制笼；独立薄头片叠到身体上会留下折痕。相邻边都落在轮廓边界、上下层被同时钳到一条弦时，会捏出放射折面；在实际坏弦加入有限的上下内点解决，不用体素高模或Decimate。头翼厚度和内部平滑仍是工程/辅助图推断。
- 同一鲨鱼的8鳍各用自己的扫描轮廓、完整根线、展/弦截面和渐薄参数。尾鳍按完整连通异尾及有效弦区间制作；原画黑轮廓不能直接包到三维卷边或厚度封口上。主鳍面原生RGB、同源内侧补色的卷边、两面接续的封边分别记录；不宣称派生区域逐字原像素。
- Boolean新顶点的自定义来源坐标不会自动可靠继承。默认零值会把一条根缝映射到原画角落，出现黑线。应回投到切割前的实际有限鳍三角形，重建原图坐标、展向和层归属；不能只补几个可见顶点。
- 静态鳍基完全贴合，仍不保证蒙皮后贴合。新根点的“身体三角形重心权重”与该身体长三角面的蒙皮插值不严格相等。本例完整490发现尾部最大约0.775mm偏差；只补最深两点不够。保留全部181个尾鳍根点，在最后两段脊骨控制区让身体共享56个真实支持点；在原有UV三角形内改善新对角线，避免连续poke留下的长细三角在切换时折叠。既不缩根域，也不改0.5mm根缝/0.02mm自由面限值。
