# 辅助材质先对部位，再对颜色和画风

2026-10-31用户拒绝红皇帝鱼初次正面图：两眼之间画了鱼身鳞片，而原侧图额头/吻部是较平滑的红色表皮。头顶完整、眼睛侧位、像素风接近，都不能覆盖这个错误。该图未进入模型贴色，不作模板。

1. **先在本鱼原图分区。** 分开看额头/两眼之间、吻端、眼圈、脸颊/鳃盖、唇缘、口内和躯干。逐区记录有无鳞片、纹样大小/方向、明暗及边界。不能从“整鱼有鳞”推导“额头应有鳞”；也不能把本鱼光滑额头推广成所有物种默认。
2. **用头部原图作为头部供体参考。** 完整侧图负责身份/画风，额头辅助图另引用实际头部裁图，明确禁止躯干纹样进入额头。提示词不能统一要求所有区域checker/scales。光滑表皮仍保留原画的像素明暗、零星斑点和高光，不整块涂成单色。
3. **完整头顶与部位材质分别审核。** 实际看完整冠顶、眼平面、吻与下巴；不能把已裁断的头加透明边就声称完整。当前红皇帝鱼第二图虽去鳞，头顶仍被裁断，重新生成完整留边图后才取色。辅助侧眼/脸颊不可靠时排除，只采用已审过的中央ROI；不借颜色供体改变头型。
4. **并排对原图、拒绝图和当前图。** 使用实际原始像素，写出拒绝原因与当前采用的确切区域。进一步看固化模型正/俯/斜和左右，确认实际覆盖的是本部位，原眼、唇纹和正常身体仍保留。供体正确不等于投影后的模型正确。
5. **冻结审阅身份，阻断误换回来。** 使用正面/中央辅助供体的新配置应提供`material_reference_review`引用，指向`kind=source_surface_material_review`、`status=operator_reviewed`的实际记录；绑定原图和当前参考SHA、旧拒绝SHA、逐区观察及对照证据。`run_material_candidate`开工前核对，中央供体与前面供体不能偷换成另一张图。该守卫不识别鳞片、不自动批准外观，不能代替第1—4步。
