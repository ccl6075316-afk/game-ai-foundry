# 嘴部执行卡：先复用方法，再适配物种

本卡是生产SOP第3—4阶段的开工入口。历史研究说明为什么；本卡规定现在怎么做。不能把“读过经验”当成“已经执行”。

## 开工先确定三件事

1. 从当前游戏清单/运行配置定位实际身体、口内和唇层。GLB可能只是骨骼和鳍的来源，实际身体可能被`.res`替换。冻结它们及源图的路径、哈希。
2. 看用户指定的最终样板及其适用范围：黑鲷135证明完整曲面→薄带→完整原像素接续；139提供运行资源/蒙皮/冷加载方法；140补上真正上唇定位、浅凸接触与保留范围；146提供已有原生公共边的接入器，**尚不是用户整鱼接受样板**。
3. 在本鱼计划中写出“复用方法、物种参数差异、未知项、保留域、实际命令入口”。只有确有缺失的能力才开发新方法；不能因为鱼名不同就重走历史失败候选。

## 方法选择

| 当前情况 | 复用入口 | 先解决什么 |
|---|---|---|
| 完整曲面和原生皮肤/口内公共边已存在 | `prepare_source_lips.py`的`native_surface`入口 → `build_native_source_lips.py` | 冻结实际候选体表；不能从旧GLB取被替换的边 |
| 必须修完整头吻/重布面 | 135完整曲面语义；139的`prepare_source_lips.py → build_source_lips.py` | 先稳定额吻、下巴和真实口裂，运输原材质/蒙皮 |
| 已有正确唇带，仅局部纹理或上唇有误 | 135接头测量/连续图；140局部参数与保留合同 | 保留已接受的另一唇和头型，只改明确支持域 |
| 鲨鱼腹位口、独立开合颌等结构不同 | 同种研究卡与`ORAL-JAWS.md`对应结构分支 | 明确结构依据及验证，不能用“近闭口/倒角”豁免本应有的带 |

选择入口后依次接入 `probe_source_lip_uv.py → build_mouth_material_continuity.py → transfer_mouth_skinning.py` 对应职责。原生身体若已有正确蒙皮，保留原绑定并验证带层权重运输，不为重跑脚本而重建身体。已运行139/146资源采用当前运行构建器冻结便携材质、重绑rest表并冷读；编号脚本的物种坐标不能成为默认参数。

现有工具不是所有嘴型通吃的一键程序。146的源口裂调整、接触细分仍有本鱼适配脚本，见`projects/pelagic-fish-146/run_candidate146.py`及本鱼配方；这些是定位实现的索引，**不能直接在新鱼上执行**。147将原生资源装配提取为`resources/scripts/volume-fish/build_native_mouth_resources.gd`，读取显式资源plan，原生带→135接续→接触后的body/lips/records/joints/atlases分别输入。复用通用算子、检查义务与顺序，重新声明本鱼输入；确需新适配器时先写清已有工具缺哪项合同，再实现该差异，不能无说明另起完整链。

装配器必须从原始运行材质构建，不能把上次安装的候选当原材质再注入一遍。隔离项目重跑时先只撤下本鱼旧候选配置，再构建新资源；通用装配器显式拒绝已含`mouth146_records`的输入，防止同名uniform重复。不要从正式游戏临时卸候选来做实验。完整眼纹保护按实际源UV冻结，不能凭“眼睛看起来离口缝很远”判断；在最终177/490前运行头宽/眼域保持检查。

## 固定施工顺序与停点

| 步骤 | 必须留下的结果 | 未满足时回到哪里 |
|---|---|---|
| A. 未清洗源图标注 | 上下外皮带、口缝、口角折返、下巴、完整眼纹分别标出；同画布同开口 | 查源图/同种资料，不猜上唇或复用另一鱼采样线 |
| B. 灰模对齐 | 额吻/眼前/上下唇/下巴正侧俯斜对照；头宽保护域 | 只修结构；禁止用贴图藏双嘴、缩颅找色或追加尖突 |
| C. 两条实际薄带 | 从真实公共边按曲面距离铺上/下带，轻微浅凸、边缘融入、嘴缝保留 | 查本鱼边界与宽度；不能把倒角声明为唇带 |
| D. 原画材质接续 | 实测身体/唇带两套UV接头；完整黑灰唇色块按原大小/相位连续 | 查实际供体/UV链；不画统一线、不抽碎黑点、不靠任意挪中央UV |
| E. 局部预检 | 原图、灰模、身体单层、带层、最终材质及同尺度接头图；顶点/边/面内接触；眼与头宽保留；实际shader/冷加载 | 根据证据回到A—D的具体失败环节 |
| F. 冻结与完整验证 | 冻结最终资源及运行依赖，再做受影响的身体077、鳍177/490、动作切换、材质锚定/LOD及真实游戏对照 | 失败按报告修具体问题；资产变动使相应旧报告失效 |

**E之前不启动最终177/490。** 局部静止/快速动作探针不是最终交付验证；它们的作用是先发现肉眼可见和资源绑定错误，避免昂贵门跑完才看嘴。完整门不是只准跑一次：真实失败必须复验；目标是避免对尚未稳定的候选重复跑。

**口角收尾也属于唇带。** 分别确认前方唇尖与眼下的后嘴角；原图后嘴角有上返折弧时，带层须沿该弧收进脸部，不能仅在口裂最低处结束。147旗鱼采用可选`posterior_source_hook`：只替换本鱼两侧上带后端，按源画布控制点投到同侧真实体表，再接回已测量的3D口缘；穿过口腔的二维射线不能作为连接。折弯超过90°时连续运输横带方向，避免按全局上下翻面。保留前段、下带与身体，仍验实际层隔离、源UV、有限三角贴合及冷读。具体点位/宽度在物种配方，不作为其他鱼默认值。

**缩口不是把大裂口搬到新位置。** 用户要求嘴巴合小、后根收上及填回下巴时，先区分原画上的深色嘴线与真正可见的口腔负空间；后段描线下面的实体皮肤不能整段挖成裂口。不要擅自固定原来的前口张开量，也不要仅按纵向最小/最大范围缩短开口。梭鲈2026-10-26反例中，带Y衰减的纯X推移虽然通过范围与正Jacobian检查，却让实际上口缘的投影顺序折回，产生向下的新缝和放射状像素拉伸。应从原版按用户指定的开度整体收合，检查实际上下口缘顺序、后根和下巴连续实体；固定相机的灰模与材质图先通过，再做最终门。该失败不构成新的可用物种模板，参数与实测结论见本鱼production review。

同一缺陷第一次适配失败，先复查已有算子输入合同、实际输出和源图；若再次失败，停止连续换参数，写出预期/实测差别并定位最小反例，再决定改适配器还是算法。局部调整通常无需问用户；源图边界/主观取舍确实无法判断时才提交具体对照。

## SOP检查器的实际边界

`mouth.implementation`必须填`source_lip_bands`或有物种依据的`anatomical_alternative`。带层分支分别声明`upper/lower`的`resource_role`、`geometry_role`、`part`和实际`node`；角色均引用`candidate_files`。几何导出JSON需有`parts`，每片含`name/vertices/triangles`。检查器会拒绝缺带、空带、坍缩三角、上下指向同一片、资源缺失和陈旧哈希。

该检查只证明声明的资源文件与几何导出存在，**不能证明导出与游戏实际网格一致或外观正确**。仍须冷加载/数组对应报告和实际层隔离图。特殊结构分支填写`reason/method_reference`，其既有结构依据/视觉证据仍必需，填了理由并不自动得到解剖认可。

旧SOP账本再次检查时须补该声明，不追造过去验收。实际接受与局部通过范围照原handoff/报告记录；145被拒绝的完成记录不可重新作为成功模板。


### 梭鲈后口填补失败补充（2026-10-26）
