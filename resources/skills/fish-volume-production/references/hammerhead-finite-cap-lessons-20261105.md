# 双髻鲨：有限鳍根面与完整尾柄截面（2026-11-05）

适用：源原画约束的双髻鲨返修。方法可复用，物种参数、像素、顶点和用户接受不跨鱼继承。路氏双髻鲨仍为已冻结成品；大双髻鲨/无沟双髻鲨本轮只是待用户查看的独立候选。

1. 头到第一背鳍的高低用本鱼侧图；头横向包络、斜桥长度与内转角用本鱼俯图。正图辅助厚度，腹图用于原生唇/腹色；辅助视图错误的鳍和侧鳃不能变成身体结构。过窄的旧颈部横宽先验会制造矩形台阶，即使头部自身轮廓正确也不放行。
2. 浅眼须沿实际有限头面求交，保留闭合背面和原始眼像素，身体独立闭合不透明。源眼在侧图的竖向登记若落在薄头翼外，先按本鱼局部面校正登记，不能为迁就眼层把头鼓厚。
3. 源图弯曲的上下唇带各自完整保护；身体/嘴在同一有限表面开口，不新增独立唇层。不同展示尺寸不能复用写死的口内切割地板高度；用实际身体最低点减所需口内深度。
4. 鳍根点同位、同骨权重或逐点混权，不等于整个有限鳍根面同位。把完整 cap 顶点及其三角面边约束进身体，UV/权重按原身体有限三角面插值；轴向分段必须保留完整根面与预算，再跑实际490姿态完整鳍根/自由鳍面。
5. float32 CDT 在原边附近可制造 sliver/非流形；不得靠删根点放行。采用原面二维重心坐标内的双精度增量插点、约束边恢复，重新验拓扑。单点/单法线嵌入不能替代完整根区。
6. 根距通过仍可能存在尾柄横截不连续。凹形原生尾鳍若没有完整 cap 中间纬线，会退化为薄片根：显式使用当前身体端截面的全部纬线/横宽，建立匹配根与近端支撑站；保留源尾端凹口及渐薄自由边，不能封桥凹口。`rebuild_shark_tail_cap.py` 为本轮采用的方法。
7. 截面测量必须同时测试有限相交线段的两个端点，且共面三角形须完整处理所有边；只取首端点/前两个顶点会误测。`check_native_shark_tail_section.py` 对当前完整 cap 内部纬线取尾侧0.1mm截面；当前尾鳍横向压成5%的内存负例必须失败。负例是明确构造的当前网格，不冒充历史拒绝资产。
8. 库内模型只作已记录的家族造型/截面参考；未知物种模型不升级为同种生物实测。鳍法向厚度仍以当前实际几何的近/中/远端射线、封边、完整接合和端/俯/斜灰模判断；不能只看有无体积。

## 2026-11-05 胸鳍位置与完整有限接合面（用户纠正优先）

用户要“拿上来一点、到蓝白交接的位置”，不是在鳍中段刷一段白色，也不是把鳍根抬到蓝区中部。R32材质代替位置、R34/R35 .58/.60体高的高位胸鳍均已被明确否定，不作为模板。以本鱼当前身体实际像素在胸鳍根纵向五截面取样，白腹与蓝灰侧色的中间过渡位置中位数为大 .28/无沟 .30体高；这里只是对齐自己的配色分界，不冒充物种解剖测量。整鳍相对原R27上移 .091601753/.038772587 m（展示4/3m），保持正常胸鳍而非背鳍位置。细节见游戏本轮blue-white-boundary.validation.json；其它鱼须重新取样，不照搬比例。

顶点到身体的距离通过，不能放行整片基帽：旧cap的三角形在换位置后跨越不同身体折面，内部会埋进身体约 .7mm；单个尾截面横宽也不能排除相邻侧影V凹/台阶。不能用颜色掩盖，也不能靠减少root_ids或阈值放宽。先完整定义原帽投影足迹，沿其边界精确切分当前身体有限面，按同一身体三角形镜像出鳍帽，拆分相接的自由边，把实际身体顶点权重复制到帽上。身体/鳍帽使用同一有限顶点和三角面，才在实际蒙皮中保持整片接合。重心挑选身体面会损失原足迹，必须用原帽完整面积与边界误差拒绝这种假修复。

预算重分配先去掉旧帽留下的冗余共面细分，再切分完整新帽；UV与蒙皮按实际源面插值，保留头、嘴眼、其它鳍和原图像素。Smooth仍严格4000tri，不能把高面或缩帽作为替代。鳍上下侧识别只用实际自由鳍面法线与源layer对应，排除新帽的内向法线，避免帽面细分数量反转上下颜色。

尾根用两边同一上缘/下缘/横宽过渡修几何连续性，灰模先比前后；尾鳍原颗粒只作有限配色校准，左右共用UV会覆盖各自身体取样，应独立两侧UV；采色与法线排除身体内部封口面。原下鳍图误带鳃纹不能作腹色证据。图像、库近似模型与RGB派生不等于生物实测；原画像素、嘴/眼保护、完整鳍根与膜面、GPU不透明、普通源冷导出、预算、实际多视和SOP仍逐鱼复验。当前两鱼只有候选提交授权，没有整鱼成品接受；不改已冻结路氏或其它成品。
