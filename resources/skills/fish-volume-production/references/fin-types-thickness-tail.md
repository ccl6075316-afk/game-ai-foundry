# 鳍型、厚度与尾柄过渡：制作前查证卡

用户于2026-10-29明确：每遇一种新的鳍结构，先调查解剖、同种多视照片、扫描/科研数据或可核来源的成品模型，再制作并记录经验；保持形状和动作所需结构的前提下尽量少面，优先试几百个**最终三角面**。讨论方案不是开工许可；本次用户已明确允许记录要求后开展单鳍实验。

## 尾柄到尾鳍

2026-10-29用户再次明确：先独立完成完整、形状正确的尾鳍，再让窄根带少量插入身体。不能以“包合/贴体”为由把自由尾鳍投影到身体、压缩或拉坏整体轮廓。根带和自由轮廓分别冻结，先看不带身体的完整鳍，再看装回的接头；单个端部射线未命中不得退化为任意最近身体面。

尾柄（caudal peduncle）与尾鳍基部应表现为连续的体积过渡：身体后段收窄并匹配尾鳍根的截面，或通过渐薄、圆滑的包合根部过渡到尾鳍。允许独立部件和预先声明的小范围根部嵌入；不接受粗身体平切端接一片等厚薄板。这里的“匹配”针对鳍根体积，**不要求整个尾柄缩到远端薄膜厚度**。

- 分别记录尾柄的侧视高度、俯视宽度、截面、尾鳍厚根和远端厚度。剖面尺寸与切线方向连续，避免台阶、悬空和突兀的厚度跳变。
- 单侧图不能决定尾柄横宽。至少用同种斜/俯视资料与灰模截面核对；物种有尾侧隆脊、异尾等结构时单独建约束，不套普通硬骨鱼。
- 硬骨鱼尾端有尾骨/尾下骨板和鳍条支持；外观可有皮肤与鳍条根包合，不能把文字“包裹”当作统一解剖结构。FAO旗鱼图谱还明确金枪鱼/旗鱼鳍条根覆盖尾下骨板的特殊情况，不能推广成全部鱼类的同一结构。
- 静止、尾摆两端与切换时分别看侧、俯、斜视接头；既验完整根缝，也验自由鳍面。外观连续不要求拓扑焊接成一体。

来源：[FAO术语图谱及尾下骨板](https://www.fao.org/4/ac480e/AC480E03.pdf)，[尾鳍骨骼/组织发育研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9357109/)。前者的具体形态示例主要是旗鱼类，不作为罗非鱼定量模板。

## 分类单位：具体物种 × 具体鳍 × 组织分区

“薄片/厚片”只是外观描述，不是解剖分类；也不能把所有鳍压成“薄膜/肉鳍”两类。下表仅是研究入口，不是穷尽分类或现成建模模板。同一种动物不同鳍、同一片鳍的不同区域都可能有不同支撑、组织和弯曲方式。

逐鳍事实卡必须回答：①具体鳍及物种/阶段；②骨质鳍条/硬棘、软骨及角质鳍条、前肢骨架、结缔组织或其他支撑；③外层膜/皮肤/肉质组织及覆盖方式；④根/中/缘截面与厚度分布；⑤可弯曲域、较刚性域及连接方式；⑥依据、同种/近缘适用范围及未知。支撑标签可组合，不能只填一个“薄/肉”枚举。查证决定简化模型的截面、弧度、几何/贴图分工和蒙皮，不要求游戏模型雕出全部内部骨骼。

- **鲸类胸鳍与背鳍/尾叶分开。** 胸鳍是含前肢骨架的鳍肢；以虎鲸为例，背鳍及尾叶由致密结缔组织构成，没有骨或软骨。不能给全身鳍统一套“前肢骨型”或“肉鳍鱼”。来源：[佛罗里达大学鲸类鳍肢资料](https://ask.ifas.ufl.edu/publication/VM227)、[NOAA虎鲸解剖](https://oceantoday.noaa.gov/killerwhaleanatomy/welcome.html)。物种细节仍逐种查证。
- **鲨鳍不当作普通辐鳍鱼薄膜。** 胸鳍的软骨支撑、角质鳍条及覆盖组织须分别调查，且不同鲨种也不能统一刚度/厚度。巨口鲨胸鳍研究发现分节软骨、弹性皮肤和活动根关节，与研究对照的高速游泳鲨种较刚的胸鳍不同。来源：[Tomita等2014原始研究](https://pubmed.ncbi.nlm.nih.gov/24465959/)；研究仅支持相应物种/胸鳍，不代替鲨背鳍/尾鳍调查。
- **肉鳍类也逐片查。** 腔棘鱼第一、第二背鳍的骨骼肌肉支撑和功能不同，不能按所属类群就把每片鳍都做成同一肉叶。来源：[Endo等2012 CT研究](https://www.jstage.jst.go.jp/article/jjzwm/17/2/17_79/_article/-char/en)。
- **辐鳍同一鳍仍分域。** 尼罗罗非鱼背鳍的硬棘区、软条区与其间膜分别记录；不能因为外观薄就统一厚度、统一弯折。
- **特化结构追查来源。** 吸盘、脂鳍及其他特化部位单独查证，不当“普通鳍拉圆/加厚”。例如鮣吸盘源于背鳍要素，不能套用其他吸附鱼的部件来源；见[吸盘软组织原始研究](https://pubmed.ncbi.nlm.nih.gov/32484929/)。

2026-10-29本次核对：NOAA正文及原始研究摘要可读取；部分PMC全文触发访问检查，未绕过检查，腔棘鱼采用可读取的论文摘要。以上建立制作前的区分依据，未提供可跨物种直接套用的厚度数值。

## 按结构分支，不统一套薄壳

| 分支 | 已有解剖依据 | 制作影响 |
|---|---|---|
| 辐鳍鱼软条/鳍膜 | 鳍条的双半鳍条、关节/分支及其间膜不同；基部与远端渐细 | 分开定义膜厚、条/棘体积、根部连接；低面代理可省略微细条纹几何，但须说明以贴图代替的内容 |
| 辐鳍鱼硬棘区 | 鳍棘与分节软鳍条结构不同，同一背鳍可以兼有两区 | 硬棘不能全按软膜弯折；轮廓尖端和根支撑需要足够控制点 |
| 肉鳍型 | 有肌肉和内部骨骼的基部叶状组织；同种不同鳍也不一定同构 | 肉质基部与远端鳍条分开，不能把所有鳍做成同一厚叶片 |
| 鲨/鳐软骨鳍 | 基软骨、辐状软骨和角质鳍条支撑，种间延伸程度不同 | 根据本物种/部位做厚根和渐薄截面；不能复用普通硬骨鱼的膜厚比 |
| 鲸类胸鳍 | 前肢骨骼包在组织中的鳍肢 | 按鳍肢外形与截面制作；鲸类尾叶/背鳍另属结缔组织结构，不套胸鳍骨型；鲸鲨仍属鲨鱼 |
| 吸附盘等特化鳍 | 不同类群由不同部件改造；北方喉盘鱼涉及胸/腹带，其他吸盘不能据此统一推断 | 查具体物种的盘缘、接触面和骨架来源，不能由普通鳍简单拉圆代替 |

结构来源：[软鳍条力学研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2359861/)，[FAO鳍棘/软条定义](https://www.fao.org/4/ac480e/AC480E03.pdf)，[腔棘鱼两种背鳍的CT研究](https://www.jstage.jst.go.jp/article/jjzwm/17/2/17_79/_article/-char/en)，[鲨胸鳍解剖研究摘要](https://sicb.org/abstracts/anatomy-and-flexural-stiffness-of-shark-pectoral-fins-in-an-ecomorphological-context/)，[鲸类鳍肢资料](https://ask.ifas.ufl.edu/publication/VM227)，[虎鲸背鳍/尾叶组织](https://oceantoday.noaa.gov/killerwhaleanatomy/welcome.html)，[喉盘鱼吸盘实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC6745484/)。这些链接建立分支，不等于各分支已经完成详细建模调查或通过验收。

## 厚度数据与比例

先定义测什么：膜的两面间距、单根鳍条/半鳍条厚度、棘直径、根部肉质包络，或整个foil最大厚度。测位沿基部到远端及前后缘分别记录，不能把AABB横宽当膜厚。

记录本物种TL/SL/FL、体高H、鳍展向长S、局部弦长c与厚度t，计算有数据支持的`t/TL`、`t/H`、`t/S`、`t/c`。TL与SL不能混用；没有同个标本体长时相应比例写未知。近缘、不同鳍、幼体或模拟器参数只可作明确标注的间接参考，不伪装本种实测。

定量例子：[Iosilevskii 2016附录B](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0163517)测的是**蓝罗非鱼O. aureus尾鳍的半鳍条**，沿鳍向长度约70mm，半鳍条厚度基部约0.8mm、远端约0.02mm；基部两半鳍条之间还有软组织。可算半鳍条`t/S`约1.14%和0.029%。这不是鳍膜厚度，也不是尼罗罗非鱼背鳍数据；该处未给同标本TL，不能据此造`t/TL`通用常数。

目前未建立跨鳍型的统一厚度/体长或厚度/体高公式。确实缺定量资料时，使用有出处的结构趋势与同种多视建立**制作推断区间**，写清数值、单位、适用范围与未知，再交实际画面审阅；不能把闭壳、不消失或原来一直使用当作厚度合理的证据。

## 辐鳍完整制作顺序：厚度减少、弧度与连接（2026-10-29计划）

适用于已查证的辐鳍分支；下面是后续执行计划，不是当前模型完成记录。新鱼/已授权整鱼鳍改造主动覆盖全部适用鳍，逐片标记保留/修改及依据。

1. **测旧模型。** 按完整根线到自由缘的几何位置采样，沿中面局部法线测正反面间距；分开膜、条/棘、肉质根部，报告根/中/梢和前/后缘的毫米值及`t/TL`、`t/H`。实际游戏缩放计入物理尺寸。横向AABB、骨骼权重或单个最薄点不能代替厚度分布。
2. **定义中面和弧度。** 冻结完整根线、主要鳍尖/凹口、根到梢方向及若干横截面，结合本物种展开资料确定静态弧面。静态弧度是模型形状，实时摆动另外由骨骼驱动；不将所有鳍做成同一个弯曲薄板。硬棘域与柔软鳍膜分开约束。
3. **定义渐薄函数。** 用几何根到自由缘的归一化距离`s`定义`t_root/t_mid/t_edge`及前后缘差异。可用`t(s)=t_edge+(t_root-t_edge)*(1-s)^p`作待拟合的工程参数形式，`p`及各测位尺寸须逐鳍确定，不是通用解剖公式；需中段厚度时分段连续插值。根部有连接体积，向自由缘平滑变薄；边缘保留有限厚度，不能两层压合。旧网格有冗厚时减少相应区域，不把整鳍统一缩薄，也不为“减少”而削掉必要厚根。
4. **分清膜与鳍条。** 普通小鳍条可经确认以贴图/法线表达，影响轮廓、支撑和物种辨识的硬棘或粗条另留必要几何；表面起伏与材质表达要记录。不能把半鳍条实测直接当整片膜厚。两条对照路线使用同一结构简化程度。
5. **两路线造壳。** A保护根线/鳍尖/凹口/权重变化区，先减中面再成渐厚壳；B直接建稀疏截站/根到梢网格，再给同一厚度。两面及封边计入最终三角面，保证法线、闭壳、无自交，避免对闭薄壳直接Collapse压合两层。几百面是目标，局部形状需要可增加面数。
6. **处理接头与权重。** 根带连续贴合身体并继承局部身体权重，远端过渡至对应鳍骨；厚度方向两面在同一解剖位置协调传权重。尾柄按侧/俯截面收窄或圆滑包合到尾鳍厚根，再渐薄，不留台阶/裂缝。允许声明的小范围根部入体，自由鳍面摆动不得二次穿体。
7. **补色、贴图和固化。** 按SOP0.3先获得无活动鳍残影的完整身体贴图，身体连接标记保留，独立鳍用独立贴图/UV。静态材质修正在Blender或离线烘焙固化；Godot只读导出、做必要显示绑定和实时动作。静态身体/鳍/口部取色的旧Godot查表须逐项迁移或证明已不需要。
8. **看形状再冻结。** 原图/派生身体贴图、无光照/正常材质、鳍灰模侧/俯/斜与根中梢截面一起看；检查尖端/根线、厚度渐变、弧度和尾接头。新进程直接冷读导出，检查原生循环、四动作及切换。问题一轮收齐、局部修，冻结后集中跑适用根基/全鳍面/身体覆盖及SOP门。图片小差异不等于动作和连接已通过。

厚度记录至少有：`fin / zone / s / local_normal_thickness_mm / display_length_kind / display_length_cm / body_height_mm / thickness_basis / camber_sections / source_hash / candidate_hash / evidence`。未知实测保持未知；已通过结果必须绑定实际模型/材质/动作输入。首个样板尚未完成时，下一鱼不能照抄其试验数值或宣称该鳍型已成熟。

## 每种新鳍型的经验记录

将事实卡放项目物种记录，将可复用结构方法回写本卡/通用工具。至少保存：

- 物种、部位、鳍型及硬棘/软条/膜/肉质域；来源URL、作者/数据身份、观察视图、测位和可用授权。
- 资料实测、图像估计、旧模型测量、制作推断分别列出；未知保持未知。
- 轮廓、根线、厚度函数与截面、尾部过渡（适用时）、尺寸比、骨骼权重、材质/UV方案。
- 最终三角面/顶点数、两面和封边成本、控制网格与细分后导出数；轮廓/根部/变形需要的局部细分。
- 试验成功与失败的具体差异、源/候选哈希、实际多视及动作证据、耗时/模型API用量、复现方法。
- 可复用范围与失效条件；详细研究和实现仍逐新类型补足，不把一条鱼成功当整类或整批验收。

成品/GitHub/扫描可用作几何和实现参考，先核对物种、测量尺度、来源许可及是否真实扫描；商品渲染或代码仓库名不等于解剖真实性。只读审阅不自动授权复制模型进项目。

低面试验先用同一鳍对照旧网格减面与低面重建；优先尝试约300/600/1000个最终三角面。几百面是目标，不是强行删点的验收门槛。先检查形状、厚度、闭壳、根部与代表动作，再按生产SOP0.1冻结后集中完整验收；研究/技术报告不能代替看图。实验候选不覆盖成品，也不沿用静态合并0.2例外来宣称鳍改造正式通过。
