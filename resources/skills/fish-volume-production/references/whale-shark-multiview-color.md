# 自有白模多视图材质烘焙

2026-11-08 用户确定的画风定义见[清爽像素鱼：B 眼睛与 C 描边](clean-pixel-fish-style-20261108.md)。重点是自然虹膜和减少脏硬描边，不是统一低饱和/全哑光或整体画风变柔。已确认二维方案先试烘焙本地罗非鱼，模型接受另记。

截图编辑供体的本轮经验：直接烘焙带光照截图会重复叠加明暗；成对旧/新截图可在固定投影上转移颜色差异，但深黑细线处的逐像素比值易放大噪声、出现灰楔。薄鳍改用实际生成图本鳍颜色配合稳健部位曝光补偿，并排除生成背景；真实眼部使用独立局部颜色及曝光校准。曝光补偿/显示比值只是艺术近似，不称物理逆色彩管理。原身体遮挡区、背腹缺视图须明确保留或补供体，不能把单张侧图说成全表面新材质。正式源/GLB、alpha、结构及多视/动作仍按下述卡执行。

## 现有成品逐鱼换材质：保留原 UV 的制作方法

用于用户指定的单鱼材质替换：自有白模约束投影、姿态与轮廓，已审原画约束本鱼配色、像素簇和部位特征，生成图只提供颜色。已有几何、完整鳍、嘴眼结构、UV、法线、蒙皮、骨架和动作作为冻结基线。后续逐条处理，每鱼重新选供体、保护区及映射参数，不默认批量改成品，也不继承另一鱼的接受。

### 输入与供体归属

从当前正式模型取得固定姿态的正交侧、俯、腹视；有活动鳍遮挡时另截隐藏鳍的完整身体侧图。按具体缺口增加视角，不强制每鱼固定四张。记录模型到世界变换、每视图投影系数、画布和分格坐标。生成图若尺寸或分格与输入不同，按实际输出逐格换算，不能沿用输入分辨率或只缩放整张图后假定格边对齐。

生图引用本鱼原画和上述白模，要求保留轮廓、口开度、鳍位与像素画风，排除烘死的水波、投影及摄影高光。先看生成图是否可作为指定部位的颜色供体；轮廓不能用来反改正确的几何。已有合格供体只调整投影或取色域即可，不为边界误采重复生图。

**所有身体供体都须排除不属于皮肤的遮挡。** 去鳍 SIDE 干净，不代表完整 TOP/BOTTOM 也干净；只按法线混色仍会将后两图中的鳍色烘进身体。分别标明身体、鳍上/下面、自由边/厚度、眼、唇及口内的可用域与遮挡，必要时补去鳍俯/腹供体或回退到同部位的可靠来源。不能把另一部位颜色擦到身体充数。原口内、真实唇缘、原眼及应保留的鳃纹使用明确保护域；生成眼与鳍影不进入体表。

### 烘回现有图集

在原 UV 三角形内遍历图集纹素，以重心坐标重建实际静止表面位置/法线，再投影到对应供体取色；按部位可见性和实际面朝向混合。成对鳍的上下面独立判断，不照搬鲨鱼的平鳍规则。左右侧腹用同光照检查覆盖，是否共用对称供体按本鱼设计确定。

保留原图集尺寸和完整 alpha，只更新授权域的 RGB；嘴、眼、唇保护域按约定保持原 RGBA。透明或未占用区域可补有限 RGB gutter，但不能改 alpha 或覆盖已占用的相邻岛。保持 nearest、原透明模式/阈值及单/双面合同。

材质实验可使用 **image-only GLB**：将新 PNG 追加到对齐后的 BIN，新增图片 bufferView，仅重定向对应 image 并更新长度；保留原 BIN 前缀及全部非图片数据。独立比较 accessor 描述与解码数组、网格/节点、蒙皮、骨架/动画、材质、纹理/采样器绑定及 alpha，不能用一次普通重导出冒充几何完全未动。这条路径用于隔离材质变量；正式交付仍须将贴图写进当前可编辑源、独立冷导出并按[最终源固化](final-asset-export.md)完成验收。

### 黑边、黑楔和接缝的定位顺序

1. 从最终体表追到实际供体、二维采样点、混合权重和原 RGB，再判断是外描边、背景误采、错误部位还是两供体色差。先看灰模：灰模已有的硬折不能靠改色判为解决。
2. **白模轮廓与生成图轮廓是两个不同合法域。** 白模内的坐标也可能落到生成图背景。取色域需结合实际生成轮廓、部位归属与有限向内余量；采样超界时向同部位有效皮肤回退，并记录距离和回退来源。大范围漂移应修配准或供体，不无限扩大最近点补色。
3. 中性深灰且与画布边连通的区域可辅助定位背景，但不能全局删黑/删蓝。天然暗背、条纹、眼嘴鳃线可能与背景接近并相连；只按暗色洪泛会误伤纹样，亮像素包络也可能裁掉整片暗背。遇到此情况直接按实际图标定完整部位 ROI，检查叠图；阈值、内缩像素和多边形逐鱼逐图选择。
4. 身体/尾柄与尾鳍接面可共用同一供体、二维位置及混色权重，再向前过渡到去鳍身体图；共用一张图仍可能共用到错误背景，须先验证取样合法。不能把一列像素拉长成色圈，也不能把端盖法线问题算成贴图问题。

### 局部复看与后续替换

新进程直接冷读候选，使用同机位、同光照的旧/新侧、反侧、俯、腹、斜及隐藏鳍身体图；按嘴→全部鳍→其余检查。重点看真实唇缘/开口、原眼、鳍反面串色、身体鳍影、背腹与尾根接缝，以及正常游戏距离的像素密度。数组/alpha完全一致只证明变量隔离，不能替代图审或当前候选的适用动作、身体、鳍根/SOP验证。

这是一套可复用制作方法，方法可行不代表所有材质问题已解决或每条鱼已接受。用户逐鱼选定替换后，再固化源与正式入口并做相应复验。方法保存在本卡；某轮实验文件经用户要求删除后，不把旧聊天路径、样例像素或退休候选当作可重放依赖。后续从该鱼当前正式源/GLB、原画和新一轮供体重新建立本鱼参数。

## 鲸鲨 R8 方法来源

### 用户已经选定原画时保留其实际颜色与亮纹（2026-11-07 旗鱼 A 负例）

用户说“拿 A 烘焙”时，A 是实际颜色供体，不只是再生一张部位图的风格参考。先标定 A 的身体、鳍与可用视角，在已有 UV 上直接取色；确需补遮挡或局部修脸时，只更新明确区域，保留原图和区域外像素验证。辅助生图/邻域补色及未画出的腹面必须分别记录，不能把全部结果称原 A 像素。

原画自带的银白亮带、鳍条高光和深浅色块是风格的一部分，不能默认全当摄影污染抹除。先用无光照底色显示检查烘焙信息是否保留，再用统一材质响应检查光照后的外观；源画亮部存在而渲染变灰时应检查材质响应、色彩映射和光照，不再反复生成颜色。脸/身体/鳍不得因不同自发光设置形成色差，但“全部改成不发光哑光”也不是通用解法。旗鱼本轮纹理驱动emission .7只为保留明亮原画的实验选值，不是跨鱼默认，更不是动态反射效果。技术保留与用户接受分别记录。

鲸鲨这次值得在其他鱼上试的是上色顺序。原画负责物种特征、配色与画风，定形后的白模告诉画师每一块皮肤朝向哪里。先用截图生成看得见的颜色，再把颜色贴回真正的曲面，转动鱼检查结果。鲸鲨的蓝灰背、暖白底和细密点纹是一次偏写实的试色。用户喜欢整体观感，但认为像素感不足，项目画风仍待选择。

## 这条鲸鲨实际怎么做

1. **从自己的模型取底图。** R7 是已审到可以试色的 8 米白模，共 9,990 个三角面。Mosi 只用于前期造型对照。把自有白模摆在同一姿态，正侧与正俯都让头朝左，以相同长度、平行投影、灰色背景截全吻端和鳍尖。两图排成一张，让生成器在同一条鱼上安排花纹。
2. **第一轮只要皮肤底色。** 指定保留轮廓、鳍位及开口，画蓝灰色背部、暖白色散点和断续横纹，额部点较细，躯干点能分别看清。排除投影、水波光和高光，以免鱼转身时灯光跟着皮肤走。此次提示词明确要求偏自然写实的游戏美术，这项选择会影响像素感。
3. **将画面分给实际表面。** 身体和各鳍展开到 UV，把同一表面点投回侧、俯图取色，按朝向混合。背冠取俯图，体侧与竖起的尾叶取侧图。胸鳍的上表面取俯图。先去掉侧图里的眼点和胸鳍遮挡痕迹，再给眼后和鳍下的身体取色，以免模型转动后出现第二只眼或第二片鳍。眼和鼻孔单独设色，口内与外皮分区。做别的鱼时要重新判断各鳍的朝向。
4. **靠翻面找出第一轮的错误。** 第一版侧面看起来已像鲸鲨，翻过来却能看见腹部一条长色带，胸鳍下侧也染蓝了。长带来自把很窄的一行侧腹颜色铺到整个腹面。第二轮直接截同一白模的正腹视，用第一张彩稿协调色调，要求腹中浅灰暖白、低对比，胸鳍下侧浅色、边缘略深。按白模的上下表面深度分开取色。背中线另有投影拖纹，收窄使用侧视颜色的区域后，正俯视点列恢复可辨。
5. **检查导出的鱼。** 将各视角烘入一张 3072 × 3072 底色图，打包到 Blender 源和 GLB。重新打开 GLB，看左右侧、正俯、正腹、斜上方和嘴部近照。核对三角面、顶点位置、绕序、法线与节点变换和白模一致。额部的点近看仍偏密，左右侧花纹相似。这是静态试色结果，动作和水下表现另验。

## 明天在另一条鱼上怎么试

挑一条侧面好看、转到斜前方或腹面就暴露问题的鱼。在独立副本上保留同一份几何、姿态和灯光，先拍旧材质。写下最想改善的两三处，例如脸颊转向下巴的色阶、鳍下面的残影、尾柄两侧的花纹。按遮挡补截图，额外视角只为具体部位生成。

第一轮用**原项目的像素风**尝试这套方法。把已审像素原画与本鱼白模截图一同送入生图：白模控制形，原画控制色板、色阶和斑块尺度。可用提示词：“保持白模姿态与轮廓；参照原画，用成簇像素表现纹样和明暗；让侧腹色阶在游戏显示大小下仍清楚；避开细碎噪点、摄影高光和连续喷涂渐变。” 最近邻采样能保留已有的像素边界，单独打开它也会保留原先的细碎渐变。

用相同角度和游戏显示尺寸并排看旧版与新像素版，集中记下拉伸、重影、接缝和串色。灰模也有的硬折先修几何；生图正确、上模才变长的先修 UV 或投影；缺失的鳍反面或错误花纹才单独再生图。若还想比较画风，在同一白模上增加偏写实一版，用相同镜头再看。分别记录“贴图是否服帖”和“哪种画风更适合游戏”，这样一条鱼就能回答两个不同的问题。

本机实例目录为 `work/whale-shark-mosi-study/r8-color/`。其中 `prompts.md` 为两轮原提示词，`bake.py` 为投影实现，`views.jpg` 是导出后六视图，`validation.json` 记录输入及导出哈希。这些是工作区实例，以上步骤可在其他机器上用下一条鱼自己的素材执行。

## 双髻鲨 R42 试用补充（2026-11-06）
大双髻鲨/无沟双髻鲨在当前自有白模上试侧、俯、腹及去鳍裸身体四面供体。`bake_hammerhead_multiview_trial.py` 将生成颜色按实际面朝向烘到普通贴图；成对鳍按实际上下层分别取俯/腹图，不再沿根加浅色圈。嘴/眼/前部鳃区保留原有来源，其余试色更简洁，与前部颗粒仍存在画风差别，尚未获用户接受。

先检查灰模法线：独立闭壳的内部帽面不能参与可见外皮平滑。`repair_hammerhead_tail_shading.py` 对两侧外皮共同按角度加权、排除内帽；只改有限接面法线，不靠变色掩盖折痕。普通源/GLB核验几何、完整蒙皮、绕序、骨架动作保持。

多图接缝也需共用投影供体。第一版用去鳍图给全部身体取色、用完整侧图给尾鳍取色，两图的尾根色值差导致竖缝。R42在无遮挡尾柄与尾鳍接面共用完整侧图的同一二维位置，再于更靠前的无遮挡身体段渐变到去鳍图；接面两侧采用相同的俯/侧/腹权重。不把一列尾根像素延长成色圈。实际初版负例与修正保留在 `projects/fishing-2d/experiments/hammer-pair-rebuild-20261105/` 的试色记录；是方法试用，不继承鲸鲨或旧双髻鲨外观接受。
