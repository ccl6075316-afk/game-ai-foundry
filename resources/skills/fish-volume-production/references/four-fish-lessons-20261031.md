# 四鱼经验收敛：嘴、鳍与受限中央材质

本文保存通用方法，不作为任何鱼的当前通过状态。状态读取逐鱼 manifest、production-review、专项报告和用户反馈；用户接受范围不能由操作者扩大。

## 不能再遗漏的检查

基础输入/预算检查后，**先嘴，再所有鳍，再其余**。嘴要实际看到口裂、下唇线、上下颌体积、完整吻端/下巴和沿左右真实唇缘的补色。仅有一条暗线、有布尔切口或机械SOP绿灯都不足。整鱼优选1500、硬上限2000三角，嘴与全部鳍计入同一预算。

| 实际遗漏/失败 | 以后如何阻断 |
|---|---|
| 蓝鳃/鲫鱼/草鱼曾把一条线当完成的嘴 | 先实际审灰模与贴图嘴近景，原切缝负例须被真实有限开口验证拒绝；颜色和下唇仍要看图 |
| 蓝鳃补色跨唇、前端下搭 | 以实际3D上下唇缘为取色坐标，逐侧输运完整原像素簇；透明口腔供体不许填成皮肤 |
| 鲫鱼前吻变宽、鼓头 | 固定完整原画尺度比较额吻和下巴；实际网格截面独立于自身profile。禁止直接用逐列alpha阶梯制截面 |
| 正面辅助图截头，或眼睛/两侧形态不对 | 先检查构图和视角；允许中央材质时只用明确中央ROI，禁止采用生成眼和整头几何 |
| 蓝鳃中央补色到眼间突然停住 | 供体ROI和目标眼区分开定义；目标眼保护限定实际左右侧支持域。保留旧纯UV矩形遮罩负例 |
| 草鱼删静态共线环后，490姿态鳍连接失败 | 不推广删环；保留动态支撑，完整同姿态鳍根/整鳍门不能被静态几何等价替代 |
| 草鱼清单复制了蓝鳃物种资料 | 核对物种卡内容/路径。sop-check拒绝species目录中与当前species身份不符的卡，即使哈希和绑定全新 |

## 中央材质可复用方法

1. 保留已确认头型、眼、口裂和鳍；每鱼独立划定自己供体的中央ROI与源图完整眼区，不复制蓝鳃坐标。
2. `author_front_mouth_chart.py` 的 `interocular_material` 在离线源中烘入材质，按实际侧向支持域保护原眼。先看局部正/俯/斜/左右视，确认眼间连续、边缘渐接、不取生成图两侧。
3. 已接受嘴需要额外保护时，配置 `preserve_mouth_rim_px` 和 `mouth_protection_fade_px`，距离取实际上下唇3D曲线。鲫鱼/草鱼本次12px+6px是本轮参数，不是所有鱼的定值。
4. `validate_material_preservation.py` 比较真实可编辑源的全部网格、拓扑、权重、变换、非身体UV/材质图和静止骨架。证明未改的部分，不能替代外观/鳍连接验证。浮点图像一次性缓存字节哈希，避免重复展开大图为Python字符串。
5. 图集重排可能有少数nearest采样边界变化。保留固定机位实际差分，不能把“几何不变”写成“所有眼嘴像素零变化”。鲫鱼/草鱼本轮嘴窗口分别4/3个差异像素，已在证据中披露。
6. 保存可编辑源与最终GLB，独立进程冷读后冻结候选；当前哈希重跑身体077、完整鳍490/072、头、动作及实际画面，最后sop-check。

## 降低重复操作与本地残留

局部阶段用 `portable/run_material_candidate.py`，先收齐局部问题，冻结后用 `run_delivery_checks.py` 集中执行完整门；不每改一个参数就重复完整录像/490。

完整门结束立即执行 `portable/prune_delivery_cache.py --delivery <本轮delivery> --execute --json`。它先校验完成状态、模型与各报告哈希，再保存明确清单，保留全数值报告、静止/极值实姿态、20个动作相位、全部静帧/视频/源/成品，删除可重建的稠密通过样本与重复帧。失败样本、未知文件、旧候选及其他目录不由此脚本擅删。

每鱼经验分三层落盘：通用方法/脚本、本鱼参数、本次真实证据。复用方法，不复用物种参数或验收结论。按用户本批要求，每新增一鱼完成后先优化、两仓库commit+push、精确保留清理，再开始下一鱼。
