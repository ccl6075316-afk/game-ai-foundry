# 梭鲈、鲯鳅、非洲鲇鱼新材质

正式入口、安装哈希、逐鱼验收与百度云核验见 [release.json](release.json)。本轮保持原有形体和运动，新风格已接受 20/28。

先烘完整去鳍身体，再处理各片鳍。独立侧图与俯图即使颜色接近，条带相位和斑纹密度也会在背侧拼接处断开。梭鲈和非洲鲇鱼改用每个原生截面的连续环向坐标，把清理后的同一供体跨背侧取样。先检查底图有无人工横缝，再在去鳍俯视和斜视实际 GPU 图上判断是否接续。近头和近尾分别渐变回原域，真实口缘、眼、腹部和鳍从独立保护域核对。具体参数随物种形体调整。

`methods/author_three.py` 直接冷读已安装 `fish.blend`。在新进程向 Blender 传入 `--background --factory-startup --python-exit-code 1 --python <author_three.py> -- --species <species> --source <正式源> --output <work 内新 GLB> --report <work 内新 JSON>`，以发布清单的模型 SHA 校验。其余两份烘焙脚本按原批次目录布局保存为制作记录，原中间候选及临时配置已退休。

本轮的当前模型、源与原始供体保留；代表性对比、专项数值、冷读、钓鱼和四动作结果已归档。完整历史生产 SOP 的资料、形态、唇供体和视频部分保留待验。
