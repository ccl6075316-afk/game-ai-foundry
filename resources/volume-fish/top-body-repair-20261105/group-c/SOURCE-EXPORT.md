# Current source-owned ordinary fish export

Maintain `export_exact_ordinary_source.py` for the current arapaima / Pacific bluefin editable sources. It depends only on Blender5/Python+NumPy and the maintained repository readers `resources/scripts/volume-fish/portable/glb_io.py` and `resources/scripts/volume-fish/patch_existing_fin_meshes.py::write`. It does not need any retired experiment model or image. Current input is always canonical `projects/fishing-2d/assets/source/fish/<species>/fish.blend` plus canonical `game/assets/models/fish/motion/eleven20261105/<species>.json`.

Blender5 drops very small skin influences in its normal glTF export. This adapter temporarily assigns explicit current-source vertex IDs, runs the real Blender exporter, then uses that stream to write the current source's normalized named weights and actual GLB joint slots. Every current source vertex must be represented and have at most four valid named influences. The temporary attribute is removed from exported primitives; the source BLEND hash must remain unchanged. Geometry, normals, UV, embedded pixels, rig and native clip are exported by Blender from that same current source; no old GLB geometry or weights are read. Nearest9728 samplers and explicit standard glTF `alphaMode=OPAQUE` / `doubleSided=false` default keys retain the actual accepted material behavior and strict native material identity. Existing explicit nondefault modes are preserved.

Invocation: Blender5 `--background --python <this-directory>/export_exact_ordinary_source.py -- <canonical-source.blend> <canonical-motion.json> <new-experiment/output.glb> <new-experiment/export.validation.json>`. Outputs must be new files in a repository experiment directory. The report records actual source/profile/model/exporter SHA, source identities, corrected tiny influences and removed temporary attribute. This is an export proof, not a physical/body/visual acceptance. Actual Godot import/UNORM16 behavior remains subject to current complete roots, whole membranes, opacity/eyes, motion, cold entry and SOP gates.

The source's current static geometry, UV, named skin and rig are authoritative. Do not revive candidate authors or historical assembly chains to rebuild an accepted fish. Giant r18 and Tuna r22 passed their current-hash gates and source repeat export before authorized experiment retirement; the compact release folders retain numerical conclusions and historical hashes, not replayable deleted media/caches.

Repair lessons: preserve original complete root domains; a closing-edge midpoint can share native UV with both skins, so integer layer tags cannot select its true fractional position. Sparse support refinement must retain actual source topology/fractions. Fin normal thickness must be measured against actual opposing shell faces, not only vertex pair length. Keep finite-chart basal depth order and physical normal-half thickness; interpolate source weights only when proven equivalent to the actual separately skinned support. Run full static self/zero-area/normal-rays/contact before full490 roots, then full membranes; all evidence binds the final cold-export model hash.
