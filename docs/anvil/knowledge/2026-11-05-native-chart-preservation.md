# 完整原生口域保存与GLB布局

同一材料保存证明不能硬编码成mesh0/primitive0/packed geometry_parts。普通多网格的首mesh可能是Anal；合法的肩部UV重绘或身体支持面split，也不等于原完整口域失效。纯造型返修不能为了满足作者报告名而假称重新涂过完整口图。

现`volume_native_chart_preservation.py`仅由显式ordinary_multimesh/packed_anterior保存报告进入。接受baseline实际快照绑定不可变旧release的物种/model SHA；当前GLB重新读取全部body/oral，自动全oral+全部真实shared lip rim及皮肤邻域、完整声明前域，逐原生UV/有向face/单射行对应/材质解析后的PNG+RGBA与sampler核对。partial前域不得标wholebody；旧packed默认和新semantic作者路径不变。

这只是材料保存门。形体、嘴结构、rig、全鳍、身体GPU与动作仍逐项做真实检查。读取全GLB和保存映射不意味着用户接受；本轮成品接受来自用户“修完且必要检查通过后直接提交”的明确授权。

实际孔雀完整body与anterior两正例、真实改UV/RGB/删oral/错source-model/缩保护map/伪wholebody/rim/未接受baseline等12case按预期；原相关37测试及独立重跑通过。精简结果见`resources/volume-fish/fish-shape-repair-20261105/native-chart-validation.json`。临时篡改模型与baseline已删，不把其路径/SHA冒称可重放输入。
