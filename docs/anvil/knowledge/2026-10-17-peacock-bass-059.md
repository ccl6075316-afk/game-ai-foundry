# 059 孔雀鲈：新增鱼种工作流实测

复用已有 Foundry 侧图 `char_b23e995ebb_nobg.png`，按原来源 workflow context/validate 和 assets review 检查。Foundry 新增一张 front 辅图，引用原侧图；没有调用生视频。通用构建器与现有四动作控制器没有修改。参数在 `resources/volume-fish/peacock-bass-059.profile.json` 和 `motion/peacock-bass-059.json`。游戏内实验在 `experiments/blender-fish/models/peacock_bass/`。

## 实测结论与限制

当前候选 059f：17 骨骼、6966 原生顶点、2 秒原生循环；8 项技术条件通过。独立 Godot 4.6.1 / RTX 5080 预览复用游戏正式 FoundryFishMotion.gd；四动作共 32 个实际蒙皮采样，成对鳍根最大距离仍在身体内，最大正间隙约0.00416 cm、最深约0.0902 cm，满足预设 gap<=0.12 cm、embedding<=0.18 cm。18 个原生动作样本与 REST 另测。24 秒实机环绕留存。

这不等于整鱼美术接受。头肩和背腹 UV 有明显拉伸及分区接缝；正面口部是静态贴图，没有上下颌几何/动作。成对鳍根接触已完整采样；中线鳍仅有相交证据，不能称完整解剖基线通过。单侧图胸鳍偏短已在059f修正：根到最远点由17.66%SL调整为22.83%SL，参考20.3–26.2%，仍保留代理测法差异；尾型偏圆等与真实资料的差异仍须逐项解决，不能由技术通过抵消。候选保留 human_review / visual pending，不装入正式展厅。

## 两个负例

- 请求鱼体外 u=0.01 截面，`measure_anatomy.py` 确实返回 missing_station_intersection，未误判为空集合通过。
- 移除 paired root_attachment 的基线：腹鳍正间隙约 0.583 cm、胸鳍存在过深埋入。旧检查器只对显式 root_attachment 启用总体门禁，故虽然局部数值失败，总体 ok 仍可为 true。新增 `--require-paired-contact` 显式要求全部成对鳍，新增 `--max-penetration-cm` 同时限制埋入；Godot 距离检查器也支持后一参数。历史默认兼容，生产调用必须主动传入这些参数。相同基线开启严格门禁后失败，059f 通过。

## 可复用的判断

单侧纹理环绕投射不能替代头部多视 UV：第一版形成额头单眼，移除烘焙眼并用两侧 surface_patch 修复；嘴部环纹需要独立、经审核的 front source。front source 不应把透明边或其眼睛重复投射到模型。图像生成、审核、冻结和模型视觉批准仍分开记录。

现有方法能快速生成可运行骨骼鱼，连接问题已有可靠复用路径；材质多视图的人工校准仍是主要返工环节。当前源图的生物比例也应在建模前测量，不能等最终验收才发现胸鳍偏短。制作前的目标表必须覆盖所有后续会比较的部件。

主工作目录名 `con` 是 Windows 保留名称；Godot 能读取部分文件，但递归创建缓存和 QA 目录会失败。实际运行移至游戏实验目录的 viewer，用户交付打包为可解压到普通目录的工程。
