# Knowledge: 巨骨舌鱼 3D 头部

## Bug Description

已安装的 v11 模型正视像圆桶，侧斜视头部也与已接受的侧面/正面像素原画有差异。正面原画显示前脸、鳃和向后上方收束的躯干层次；v11–v14 的严格正交前视主要显示圆形截面。`volume validate` 的闭合网格、蒙皮、贴图尺寸等机械检查均通过，但不能验证这一观感。

## Attempted Hypotheses

### Attempt 1 — v12

- **假设与改动：** 只加宽前肩到前头的横向 `body.sections`，让正脸接近后躯宽度。
- **结果：** 正面眼睛比 v11 清楚，但外圈仍圆；没有通过视觉审核。
- **收获：** 后躯投影是 v11 外圈来源之一，v12 的最大宽度已移到 u≈0.808 肩部；不能继续把整圈只归因于后躯。

### Attempt 2 — v13

- **假设与改动：** 保持 v12 其他值不变，只加宽 u≈0.865/0.911/0.945 的前头深度。简化前视投影估算肩部可见面积减少约 25%。
- **结果：** 肩带缩窄，但侧面与斜视的眼、鳃和红色纹理被明显拉伸；没有通过视觉审核。
- **收获：** 几何宽度和正面投射 UV 范围耦合；正面宽度改善会破坏侧面原画。

### Attempt 3 — v14

- **假设与改动：** 回到 v12 几何，只把 `head_projection.side_limit` 从 0.99 收紧到 0.65。
- **结果：** 侧视原生眼鳃更接近侧面原画，但正视出现重复眼睛和交叉脸纹，圆形外圈仍在；没有通过视觉审核。
- **收获：** 缩小正面覆盖会露出侧面贴图的眼；扩大覆盖又损害侧视，单个阈值无法划清纹理归属。

## Architectural Concerns Raised

当前构建器用一个椭圆环闭合身体承载完整侧面图，再用按表面法线渐隐的正面图叠在头部。两个图都有眼、鳃和嘴，在交界处争夺同一可见区域；正交正视还把肩部与更远的躯干投影成圆环。单调厚度或覆盖阈值只能转移问题，不能同时保证正面、侧面和斜视。

## Recommendations

保留 v11 为已安装模型，v12–v14 handoff 保持视觉待审且不复制到游戏。下一步先针对用户指出的主视角，制作只读的前/侧纹理归属图和三视几何轮廓对照；再设计独立头部几何，以及明确的正侧贴图区域与遮挡/混合边界。新方案须按 Foundry `plan → build → validate → render → 实际 Godot 审核 → accept` 重新验收，不能沿用本轮的机械检查结论。

## What We Learned

Blender 便携版实际存在于 `/private/tmp/fish-blender-toolchain/mounted/Blender.app`，只是没有进入 PATH；沙盒内 Metal 初始化会崩溃，沙盒外可构建。模型可生成与头部观感合格是两件事；侧面原画与正面辅助原画的眼鳃区域必须预先明确归属。
