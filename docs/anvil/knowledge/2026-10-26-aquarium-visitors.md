# 水族馆游客实验：复用、造型与验收（2026-10-26）

本轮交付是可进入现有大厅的游客试装。v1 已被用户明确否定；v2 通过代码、行为和实际渲染检查，外观仍待用户验收。提交代码不改变该状态。

## 结论与实现边界

成年男、成年女、老年男、老年女、男孩、女孩共六种基础网格，每种提供三套经源图审核的外观，共十八种组合。组合标签选择具体参考人像，不作为按人群概括解剖特征的规则。六组 MultiMesh 共用一张 2048×1024 nearest 图集、一个材质和 GPU 动作；每实例只传动作相位、动作权重、衣服配色和外观选择。没有逐人骨架、物理体、材质或灯。

“十八种外观”不等于“十八套独立角色系统”，也不等于相同人数的三倍开销。变化主要存在共享顶点属性和 UV 中。人数、顶点量、可见性和路径更新更直接影响本轮开销。但本轮没有做固定模型细节的六种/十八种受控对照，不能据此量化两者差距。

试装默认 24 人、会话上限 200；人数不进入存档。六种网格为 4620/5164/4620/4620/4648/4812 三角形。当前 252 平方米大厅按可走空间限制实际人数；3000 人是后续大场馆目标，尚未实现或测量。

## 已验证的方法与失败教训

| 问题 | 原因与处理 | 后续要求 |
|---|---|---|
| v1 技术通过但造型被否定 | 简化造型未达到现有像素美术的表现要求；v2 重新制作衣服、比例和头部体积 | 技术通过与用户美术验收分开记录，先看实际模型再推广 |
| 脸拉长、重复耳朵、下颌色带 | 把源图轮廓、头发和耳朵一起包到皮肤上；改为独立脸部图块、干净面颊供体和几何耳朵 | 每张人像按实际像素尺寸量地标，身体图与头部图分别管理 |
| 头发遮脸、发际线消失 | 非平面发壳底盖形成垂帘；通用椭圆又埋入实际颅骨 | 删除发壳底盖，由闭合颅骨遮住内部；沿实际颅骨建立发壳并检查正侧背面 |
| 裤裆突片、衣摆穿插 | 独立大腿段与衣摆重叠 | 使用统一骨盆、腰带和衔接衣摆；袖口与前臂根部也须对齐 |
| 动作枢轴变值 | 顶点颜色发生颜色空间转换 | 枢轴和肢体编号存浮点 CUSTOM0，导出后冷读全部自定义属性 |
| 灰模无法判断五官 | 背光只显示轮廓 | 正面主光下检查灰模正、侧、斜视，同时保留贴图与行走证据 |
| 性能采样被鼠标操作污染 | 只关闭普通输入仍有 GUI 输入改变相机 | 禁用 GUI/其他输入并逐帧断言相机、布局和源文件不变 |
| 无头检查被误当作 GPU 证明 | dummy renderer 的实例颜色读回为默认值 | 行为测试、实际渲染器属性读回、画面人工审核分别取证 |

Godot 4.7 的 `get_render_info` 使用两个参数。早期调用/相机控制失败的测量不纳入最终性能结论。生成前缺少 canonical input fingerprint 的计划先修输入；授权网络的失败任务沿同一 manifest 恢复，不重复开新一轮。

## 当前证据与性能

Apple M4、Godot 4.7.1 Mono、Forward+ Metal，1920×1080 大厅 SubViewport，固定相机按 0→24→100→200→0 人顺序，各预热 45 帧、测量 180 帧：

| 实际人数 | 整馆帧耗时中位数 ms | 游客 CPU 中位数 ms |
|---:|---:|---:|
| 0 | 7.848 | 0 |
| 24 | 8.3025 | 0.133 |
| 100 | 8.8805 | 0.4265 |
| 200 | 10.114 | 0.7835 |
| 再次 0 | 8.0465 | 0 |

这是一次有顺序的实际运行，基线漂移 0.1985 ms，没有独立 GPU 计时。不能外推 3000 人，也不能把 v1/v2 模型精细度变化当成六种/十八种外观对照。

最终行为检查 92 项通过，采样 133769 段移动；30 秒内 24 人中的 23 人移动超过 1 米，并观察到停留观赏。离散动作扫描最大水平半径 0.356670 m，导航半径 0.37 m。静止鞋底为 0；采样最低顶点为 −0.779～16.547 mm。没有 IK 或锁脚，离散证据不证明连续接地或无滑步。

## 保留、复现与后续

复用代码在 `resources/scripts/visitors/`，可编辑参数在 `resources/visitors/visitors-v2.profile.json`。运行成品与源图、冻结 brief/提示词、生成凭据保存在独立游戏仓库 `game/assets/visitors-v2/`。`build_visitors_v2.py` 的精确离线构建命令保存在游戏 `output/visitors-v2/review/asset-handoff.json`。

游戏仓库 `plans/reviews/aquarium-visitors-v2/experiment-summary.md` 汇总用户状态、复现入口和逐项证据；`submission.validation.json` 记录本次额外清理的逐文件 SHA256、字节数和历史引用去向。v1 只保留小型可复现的被否定对照；v2 保留 29 张最终模型图、4 张大厅图及唯一失败样本。重复截图、旧日志、临时探针、示例工程和可重建缓存按明确清单删除，不清理其他任务。

下一轮应先根据用户对现有 v2 画面的反馈决定造型，再做更大场馆与人数阶梯测量。当前发型/胡须有简化，外观顶点变形复用基础法线；大厅蓝色光照影响辨色，Windows 与打包导出未验收。
