## 工程理解

### 当前证据

- 大厅逻辑在 `Main.Screens.BuildAquariumHall` + `AquariumHallView`；`tank_view` 仍走 Main 切屏。
- `GODOT-ARCHITECTURE.md` 已要求 `aquarium_hall` / `tank_view` 独立 `.tscn`，禁止继续往 Main 堆玩法。
- 缸数据现为墙上矩形格 `RectW/H` + 容量由面积推导；**无进深维度、无价格曲线、无物件深度**。
- 地板：`aquarium_floor.gdshader` 对矩形做中心透视 UV，易扭曲；地砖含白边需裁 content UV。
- 水色：`sin×sin` 焦散造成菱形纹；与「远糊近清 + 弱光」目标不符。
- brief 分册：墙程序绘 + 地砖变形铺；水色代码叠层；禁止整厅透视图当地板。

### 工程结论

水族馆交付拆成四块能力，共用 **连续进深轴 `d`**：

| 能力 | 性质 | 说明 |
|------|------|------|
| 建馆 | 向导，非编辑器 | 定制展墙画布宽×高（可后续再扩） |
| 墙面编辑 | 画图类工具 | 在展墙上画/改缸的开窗矩形，并设定该缸 `w,h,d` |
| 鱼缸编辑 | 内景工具 | 水色/光色、物件摆放（位置/缩放/进深） |
| 游览/贴窗 | 运行时 | 大厅看缩略缸；贴窗观赏时鱼在 `[0,d]` 游动 |

渲染一律 **2D 假深度**：`d → scale / visibility / draw_order / 折射强度`。

## 目标

1. 修正现有大厅/水色/地板表现缺陷（见成功标准「表现修复」）。
2. 建馆时可定制展墙画布尺寸；缸体可定制连续宽×高×进深，价格由曲线计算。
3. 交付墙面编辑器（画缸）与鱼缸编辑器（内景+进深摆件）。
4. 鱼（及允许的物件）沿进深轴活动：近大清、远小淡，超过可见阈值不可见。
5. 水族馆从 Main 绞杀迁出到独立 Screen Scene（+ 编辑器子场景/模式），Main 仅路由。

## 非目标

- Godot 3D / Camera3D 真缸、真折射光学模拟。
- 用户自定义「名义层数量」作为主深度模型（可用进深快捷档，非层系统）。
- 本轮重做整厅 AI 背景图、游览角色完整 AI、全 prop 资产生成。
- 把商店/仓库/纪录片一并迁场景（可后续）。
- 精确物理流体；「蒙版折射」指 2D 近似强度随 `d` 变化，非屏幕空间真实折射管线（可分波加强）。

## 当前架构约束

- Godot 4 .NET；像素风 2D；Session + Catalog 模式。
- 须对齐 `projects/fishing-2d/GODOT-ARCHITECTURE.md`：一屏一 Scene、System 可测、UI 不直接散改经济字段（指导级）。
- 展墙可扩展：禁止唯一依赖固定构图整厅透视图。

## 方案选择

**2D 连续进深 + 双编辑器 + 独立大厅场景（已确认选型）**

1. **深度模型**：每口缸 `faceW, faceH, depth`（连续；单位：画布格或逻辑单位，plan 锁表）。价格 `price = PriceCurve(faceW, faceH, depth)`。
2. **实体深度**：鱼/物件 `d ∈ [0, depth]`（0=贴玻璃近端）。渲染映射：
   - `scale(d)` 单调递减
   - `visibility(d)` 单调递减，`d >= fadeEnd` → 不可见
   - `z-index` / 绘制序随 `d`（远先画）
   - 水色雾与近似折射强度随 `d` 增加
3. **建馆**：向导设定 `WallCanvasWidth/Height`（展墙面）；不是画笔工具。
4. **墙面编辑**：网格上矩形工具（创建/移动/缩放开窗）；属性面板调 `faceW/H/depth` 与水型；类画图：吸附、最小尺寸、防重叠。
5. **鱼缸编辑**：背景/主色/弱光参数；物件库拖入，调位置、缩放、`d`；预览同一套假深度渲染。
6. **场景**：`aquarium_hall.tscn` 游览；墙面编辑为大厅编辑模式或挂载子场景；`tank_editor`/`tank_view` 同场景双模式或双入口，与大厅分离；Main 只 `Navigate`。
7. **表现修复（与功能同 Spec，不可甩出范围）**：
   - 地板：弃用矩形中心扭曲 UV；改为 **梯形/网格变形铺砖** 或「轻透视 + 正常 fract 铺砖」，裁白边；加宽展墙时地板随画布长度延伸，不把「加宽」表现成地板密度乱变。
   - 水色：去掉 `sin×sin` 菱形干涉；改为单轴弱波 + tint 梯度（远浓近清）。
   - 大厅不再垫旧「大厅背景/小型缸背景」图抢戏；缩略缸为迷你玻璃窗预览。

## 被排除方案

- 真 3D 缸 / 大厅 2D+缸内 3D 混合。
- 固定 3/5 名义层作为唯一深度（无连续 `d`）。
- 进深仅档位、面尺寸不可连续调（已否决；采用连续三维 + 曲线）。
- 继续在 `Main.Screens` 堆编辑器。

## 边界与失败模式

| 风险 | 缓解 |
|------|------|
| 假深度看起来「平」 | 验收曲线：近远 scale 比、fadeEnd 必须可感知 |
| 编辑器状态污染游览 | 明确 Edit/Tour 模式；未应用变更可取消 |
| 深度单位与墙格混淆 | 领域语言区分「面格」与「进深单位」；存档字段分列 |
| 价格曲线被刷 | curve 单调不减；设最小/最大 clamp |
| 迁场景中断可玩 | 绞杀式：先修表现 + 数据模型，再迁 Scene，保持入口可玩 |

## 显式假设

1. 「宽高」在建馆指展墙画布；在缸体指开窗面；「深」仅指垂直玻璃向内的厚度。
2. 第一版物件种类可极少（色块/现有 prop），重在深度与编辑管线。
3. 价格曲线具体系数 plan 阶段给出可调表，本 Spec 只要求单调曲线形态。
4. 用户确认本 Spec 后，先前 MVP 临时代码以本 Spec 为准重构/替换。

## 领域语言

| 术语 | 含义 |
|------|------|
| 展墙画布 | 建馆定制的墙面网格（宽×高格），可再扩展 |
| 开窗 / 缸面 | 墙上矩形 `faceW×faceH`，观众看到的玻璃范围 |
| 进深 depth | 缸厚度；鱼可游的 `d` 上界；影响价格与远距表现 |
| d / 假深度 | `[0,depth]` 逻辑轴；0=近玻璃 |
| 墙面编辑 | 画/改开窗与缸三维属性的工具模式 |
| 鱼缸编辑 | 单缸内景、光色、物件与其 `d` 的工具 |
| 贴窗观赏 | 运行时全屏看单缸（可与编辑同场景预览模式） |
| 价格曲线 | `PriceCurve(faceW, faceH, depth)` |

## 功能需求

### F1 表现修复（阻塞验收）

- F1.1 地板形状可读为「墙前地面条带」，无菱形/空洞扭曲；白边不铺进可见区域。
- F1.2 加宽/加高展墙时，视觉变化在 **墙面画布**（与开窗布局），不误绑为地板 tile 密度异常。
- F1.3 水色无菱形干涉纹；远浓近清可辨。
- F1.4 墙上缸为迷你玻璃预览（水色+内容暗示），非纯文本条。
- F1.5 贴窗观赏不依赖「小型缸烤景」旧底图作为唯一水体来源。

### F2 建馆

- F2.1 未建馆时进入向导：设定展墙画布宽高（连续或整数格，plan 锁）。
- F2.2 建馆后可进入游览；扩展画布保留已有开窗（越界规则 plan 定：禁止缩小吃掉缸 / 或提示）。

### F3 墙面编辑

- F3.1 工具：新建矩形、选择、移动、改大小；网格吸附；防重叠。
- F3.2 选中缸可编辑 `faceW, faceH, depth`、水型；实时显示 `PriceCurve` 估价。
- F3.3 提交后写入 Session；游览模式显示缩略缸。

### F4 鱼缸编辑

- F4.1 编辑主色/弱光/水色参数（代码参数，非生图）。
- F4.2 放置物件：位置、缩放、`d`；预览假深度。
- F4.3 可设定本缸鱼允许的游动进深范围（默认 `[0, depth]`，可收窄）。

### F5 运行时假深度

- F5.1 鱼在允许范围内更新 `d`（可随机缓动或简单 AI）；近大远小、远淡至不可见。
- F5.2 多鱼/物件按 `d` 排序绘制，行为符合「可游到离用户更远/更近」。

### F6 场景架构

- F6.1 `aquarium_hall` 独立 `.tscn`；编辑器不驻留 Main。
- F6.2 Main / Hub 仅路由进入；迁徙期可临时桥接，plan 给完成定义。

## 非功能需求

- 编辑器操作在 1080p 下可点选；矩形工具延迟可接受（无联网）。
- `PriceCurve` 与 `scale/visibility` 映射纯函数，可单测。
- 不引入 3D 渲染特性依赖。

## 安全关注点

- 无联网；无 PII。注意 Session 存档字段兼容（旧缸无 depth 时迁移默认值）。

## 成功标准

1. **表现**：F1.1–F1.5 在手工进厅/贴窗可观察通过。
2. **建馆**：可设非默认画布尺寸并保留。
3. **墙编**：可画至少两口不重叠缸，分设不同 depth，价格随 depth 上升。
4. **缸编**：可放至少一种物件并改 `d`，预览近大远小。
5. **假深度**：鱼在贴窗中可见远近缩放与淡出；极远不可见。
6. **架构**：水族馆主逻辑不在 `Main.Screens` 内继续扩张；存在独立 hall 场景入口。
7. `dotnet build` 通过；核心曲线有单元测试。

## PR Review 关注点

- 深度单位是否与面格混淆。

- 地板/水色是否仍含菱形或错误透视。
- Main 是否又被塞进编辑器逻辑。

## 开放问题（非阻塞，交 plan）

1. `face` / `depth` 的具体单位与数值范围、默认值表。
2. `PriceCurve` 系数与货币平衡。
3. `scale(d)` / `visibility(d)` 曲线形态（线性 vs 平滑步）。
4. 墙面编辑：模式切换 vs 独立 `.tscn` 文件级拆分（本 Spec 允许二者之一，plan 选定）。
5. 缩小展墙画布时已有缸的冲突策略。
6. 「蒙版折射」第一波强度：仅 alpha/扭曲近似到何程度。
