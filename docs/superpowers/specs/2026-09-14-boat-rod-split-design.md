# 战斗前景：船与鱼竿拆分 + 抛竿/拉杆动画

日期：2026-09-14  
项目：`projects/fishing-2d`  
状态：设计已口头确认；待实现计划

## 1. 目标

解决当前战斗前景「船舷碎块 + 竿焊在一起」的违和感：

- 船与鱼竿**分开生图**
- 船画得**更完整**，战斗里只把一部分放进画面
- 需要**抛竿**与**拉杆**动画
- 竿动画**只要竿，不要手/人**（第一人称）

## 2. 方案

采用 **A：船静图 + 竿三态（静帧 / 抛竿视频 / 拉杆循环视频）**。

不采用：单视频切时间轴（B）、纯代码旋转弯曲竿（C）。

## 3. 资产清单

| 名称（brief） | 类型 | 说明 |
|---------------|------|------|
| `钓场_战斗前景_船` | `texture` / image | 完整小船，透明底；无竿、无人；沿用现有木船配色与像素密度 |
| `钓场_战斗鱼竿_角色` | `character` / image | 仅竿+轮，透明底，无手；作 pose 参考静帧 |
| `钓场_战斗鱼竿_抛竿` | `character_pose` / video | `reference_asset` → 鱼竿角色；`action: cast`；**不循环**；短片段挥竿出线 |
| `钓场_战斗鱼竿_拉杆` | `character_pose` / video | 同上参考；`action: reel`；**循环**；搏鱼拉杆 |

待抛/待机态：`AwaitCast` 与 `WaitingBite`（及 Fighting 松手、Result）均使用同一张 `钓场_战斗鱼竿_角色` 的 `*_nobg.png`，不另开「待抛」生图。若实机觉得「未抛」与「已抛等咬」需要区分，再补一张伸出静帧。

### 3.1 作废

- `钓场_战斗前景_船身与鱼竿`（`fg_5a1f8c3e7b`）改为 `availability: placeholder`（或等价退役），战斗场景不再引用。

### 3.2 生图约束（摘要）

- 船：整船入框（侧视略俯，船头～中段可读）；风格对齐战斗背景与现有木船。
- 竿：单独透明底；抛/拉视频中**不得出现手、手臂、渔夫**。
- 构图比例：船可用宽屏前景比例；竿角色/pose 对齐现有鱼 pose 的 16:9 视频管线（以 brief/sizing 契约为准）。

## 4. 战斗画面裁切

- **生图**：完整小船。
- **运行时**：放大并锚在视口右下；裁切后主要露出船头/内侧船舷，船尾与大部分甲板在屏外。
- **叠层（下→上）**：天空 → 远景 → 水面 → 鱼 → **船** → **竿** → 鱼线 → HUD。
- 鱼线锚点跟竿 tip（由竿精灵尺寸/布局标定，替换硬编码 `_rodTip` 对旧合成图的依赖）。

## 5. 阶段 ↔ 表现

| `CombatPhase` / 输入 | 船 | 竿 |
|----------------------|----|----|
| `AwaitCast` | 静图 | 待抛静帧 |
| Space 触发后、抛竿片播完前 | 静图 | 播抛竿一次 |
| `WaitingBite` | 静图 | 待抛静帧（可理解为已抛出后的伸出态） |
| `Fighting` + 按住拉杆 | 静图 | 拉杆循环 |
| `Fighting` + 松手 | 静图 | 待抛/微弯静帧 |
| `Result` | 静图 | 待抛静帧 |

规则层：`CombatSystem` **不改**（张力/体力/距离等）。仅 `FishingBattleScreen`（及资源路径）改表现。

抛竿与 `StartCast`：Space 时开始播抛竿并照常 `StartCast`；若片长短于咬钩等待，自然落在 `WaitingBite` 静帧；若片长略超，播完再切静帧即可（不以动画阻塞战斗逻辑）。

## 6. Godot 改动范围

- `BoatForegroundRes` 拆为船纹理 + 竿节点（静帧 / AnimatedSprite 或等价视频帧序列）。
- 输入已有：`cast`（Space）、`click_reel` / 左键按住。
- 场景：`fishing_battle.tscn` 增加竿节点；船节点只绑新船图。
- 不改战斗数值与胜负判定。

## 7. 验收标准

1. 战斗中只看到船的一部分，但能辨认为完整船的裁切，而非孤立木条。
2. 船与竿为独立层；竿在抛/拉时有可见运动。
3. Space → 明显抛竿一次；按住拉杆 → 拉杆循环；松手 → 停循环回静帧。
4. 竿相关画面无手、无人。
5. 鱼线始终从当前竿 tip 出发。

## 8. 非目标

- 不引入可见渔夫全身/半身。
- 不在本设计中做多级钓竿换皮（仍可后续用同一套 pose + 换色/换参）。
- 不重做淡水/海水背景，不改鱼游动资产。
